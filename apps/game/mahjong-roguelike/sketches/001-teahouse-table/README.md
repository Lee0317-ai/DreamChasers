## Variant: 茶馆牌桌

### Design stance
把玩家的第一眼放回牌桌和牌山，HUD 退成茶桌边缘的牌匾和筹码。

### Key choices
- Layout: 顶部只放关卡和两个核心数值，中部大牌桌，底部手槽和动作栏。
- Typography: 标题和动作使用宋体类字体，让“胡了卜”更像牌局而不是网页工具。
- Color: 深木色、茶绿桌面、奶白麻将牌，强调桌面氛围。
- Interaction: 可用组合按钮发火，关键可点牌外发光。

### Trade-offs
- Strong at: 氛围和“这是个麻将牌局”的第一眼识别。
- Weak at: 信息密度低，局外成长/流派/事件信号不够明显。

### Best for
适合把 Cocos 正式版做成沉浸牌桌，先让玩家觉得“这游戏有味道”。
