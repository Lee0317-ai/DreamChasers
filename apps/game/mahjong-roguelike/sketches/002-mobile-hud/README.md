## Variant: 手游 HUD

### Design stance
优先解决玩家“现在该看哪、能点什么、差什么”的问题，牺牲部分氛围换清晰度。

### Key choices
- Layout: 顶部状态和 Boss 目标，中央牌山，下方动作按钮、工具、手槽三段固定。
- Typography: 系统字体加粗，保障手机小屏可读。
- Color: 深绿底、金橙可操作状态、灰暗不可操作状态。
- Interaction: 可用按钮和关键牌有强高亮，提示条明确告诉玩家下一步价值。

### Trade-offs
- Strong at: 读信息快，适合朋友试玩和移动端发布前验收。
- Weak at: 氛围没有茶馆版强，容易偏普通手游功能 UI。

### Best for
适合先把 Cocos 版做到“能玩、看得懂、不误触”，作为正式工程落地的保守路线。
