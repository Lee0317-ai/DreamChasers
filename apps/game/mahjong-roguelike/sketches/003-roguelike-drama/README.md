## Variant: 国风 Roguelike

### Design stance
把风场、事件、Boss 和流派做成一眼能感受到的戏剧身份，让它不像普通消除游戏。

### Key choices
- Layout: 顶部是 Boss/风场仪式感，中段事件卡和牌桌，底部保留手槽与动作。
- Typography: 宋体、印章、卷轴感，强化“牌局命运感”。
- Color: 深红、暗绿、金色，制造高阶周目和事件压迫感。
- Interaction: 可用动作像触发大招，关键牌带红金预兆光。

### Trade-offs
- Strong at: 记忆点强，Roguelike 味道最足。
- Weak at: 容易压住牌山本身，正式落地要克制，不然会太吵。

### Best for
适合高阶周目、Boss 关、事件关的视觉方向；普通关可以只借它的风场/事件组件。
