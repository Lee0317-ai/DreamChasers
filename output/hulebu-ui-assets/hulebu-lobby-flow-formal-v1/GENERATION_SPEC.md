# 胡了卜完整局外流程正式视觉母稿生成说明

## 1. 任务与工具

- 任务：T271。
- 生成工具：PPTOKEN `gpt-image-2` 兼容 Images API。
- 生成日期：2026-08-11。
- 目标画布：`390×844` 竖屏；生成请求使用接近目标比例的 `768×1664`，服务返回尺寸以 `manifest.json` 实测值为准。
- API Key 只作为命令临时环境变量使用，没有写入仓库或本说明。

## 2. 统一视觉约束

- 原创中国麻将牌 Roguelike 解谜游戏，不使用赌场或真钱表达。
- 视觉材料统一为青玉漆面、旧金描边、象牙宣纸、深胡桃木和克制朱砂色。
- 场景使用宋式茶室、园林窗景、白色桂花/木樨与青瓷器物。
- 页面不使用手机壳，不使用人物，不使用英文、品牌标志或水印。
- 所有关卡名、数值、按钮文案和状态说明由 Cocos 运行时文本叠加，不依赖生成图文字。
- 母稿用于视觉构图和组件拆分，不允许整张作为不可交互背景直接接入运行时。

## 3. 母稿提示词摘要

### 登录与标题

- 大标题 `胡了卜` 与玉印 `胡` 作为第一视觉信号。
- 下方一枚朱砂主按钮框、两枚象牙次按钮框和一块说明区。
- 保持品牌氛围，但登录入口不能被装饰吞没。

### 局外大厅

- 顶部头像和资产条。
- 第一层是继续本轮主板、进度轨和朱砂主按钮。
- 第二层是主线、模式、图鉴、成长四入口卡。
- 底部是四项固定导航。

### 模式选择

- 五条纵向模式入口：主线、无尽、每日、高阶、图鉴。
- 图标分别使用山路、无限牌环、日历印章、四风罗盘和图鉴书。
- 高阶使用锁定态；主线和每日使用朱砂强调态。

### 主线地图

- 纵向宋式山水园林地图，金色路径串联关卡节点。
- 区分完成、当前、锁定和 Boss 四种节点。
- 节点数量由运行时生成，母稿只固定路径和状态语言。

### 胜利结算

- 朱砂双金边胜利印章、标题区、三项统计、解锁横幅和双按钮。
- 氛围庆祝但克制，不堆叠彩纸或强闪光。

### 失败结算

- 深木与暗青玉结果印章、失败原因、三张牌建议区、存档说明和双按钮。
- 语气支持玩家继续尝试，不使用破碎、骷髅或惩罚性视觉。

## 4. 验收结论

- 六张母稿保持同一材质、边框、花木和光照体系。
- 登录、大厅、模式、地图、胜利和失败具有清晰不同的信息架构。
- 生成图没有可作为正式运行时文案的数据；所有空白牌匾和按钮框都需由 Cocos 文本层补齐。
- 下一步只拆批准的组件家族，不重复生成整套页面。
