# 胡了卜弃牌 UI v1

本资源包为 `390 × 844` 竖屏牌局设计弃牌交互，双倍图资源基准为 `780 × 1688`。视觉沿用青绿玉石、暖象牙、旧金、深胡桃木和克制朱砂红。

## 交互顺序

1. 待机：沿用截图右侧工具栏显示“弃牌”入口；不可弃牌时使用 disabled 资源。
2. 选择：点击入口后，主槽可弃牌进入轻微呼吸态，动作栏上方显示“请选择一张手牌”。
3. 选中：牌上浮约 18 设计像素，叠加朱砂与旧金双描边。
4. 确认：确认控件贴近右侧弃牌入口，动作栏与底部手牌槽保持原位。
5. 完成：牌移动到牌河，短暂显示成功提示，随后退出弃牌态。

牌河最多两格，但空状态不绘制永久空框；只有已经弃入的真实牌才显示。所有中文由 Cocos `Label` 绘制。

## 建议动画

- 进入弃牌态：提示条 160ms 上浮淡入。
- 选中牌：Y 轴上浮 18px，时长 120ms，`backOut`。
- 确认条：180ms 自下淡入，不遮挡主牌山。
- 弃牌成功：牌用 220ms 弧线移动到牌河，成功提示停留 650ms。
