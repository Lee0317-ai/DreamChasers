# 胡了卜铜钱资产和 3 项局外升级实施计划

## 目标

让 `/games/hulebu` 的局外铜钱成为真实可消费资产，并让 `备用槽 / 满槽护符 / 初始道具` 的升级在下一轮主线 run 中真实生效。

## 步骤

1. 先补 web 测试，锁定：
   - 升级面板
   - 3 项升级名称
   - 升级购买相关文案
   - iframe URL 里的升级参数
2. 实现局外资产与升级状态：
   - 本地持久化
   - 消费扣钱
   - 满级与不足提示
3. 给 iframe 主线追加 `reserveBonus / shieldBonus / toolBonus`。
4. 在静态 Demo 与原型源文件中读取参数并叠加到 run 初始状态。
5. 跑测试、构建、脚本语法和浏览器验收。
6. 更新模块文档、任务分片、领取分片、当天进展和完成记录。

## 验收重点

- 买完升级后，刷新页面仍保留。
- 开一轮主线时，升级效果不是只在外层显示，而是真的影响局内初始容错和道具数。
- 主槽继续固定 8 格，不被局外成长破坏。
