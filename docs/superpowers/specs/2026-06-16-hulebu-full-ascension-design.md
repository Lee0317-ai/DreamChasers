# 胡了卜高阶周目完整版设计稿

- 日期：2026-06-16
- 任务：T176
- 状态：待验收

## 1. 目标

把当前高阶周目从“两个入口 + 轻量词缀”的第一版，补成一个真正可持续扩展的高阶体系。T176 之后，高阶应该具备四档轮回、局外可装备能力、局内专属奖励和更明确的限制压力。

## 2. 范围

本任务只做高阶周目完整版：

- 扩展为 `东风场 / 南风场 / 西风场 / 北风场` 四档。
- 局外新增 `高阶配置` 面板，用于装备高阶可用能力。
- 高阶 run 的奖励节点支持专属奖励和能力组合。
- 不同高阶档会影响能力槽位、起始工具、洗牌权限、奖励衰减和 Boss 压力。
- 外层和内层都能清楚显示当前高阶档与限制。

不做 Boss 第二版、特殊事件池第二版、普通局外升级重做、Cocos 追平、排行榜、付费、广告或账号体系扩展。

## 3. 四档高阶口径

- `东风场`
  - 第一档高阶，继续作为已通关后的入口。
  - 限制较轻，保留当前第一版的理解成本。
- `南风场`
  - 增加起始资源限制和更稳定的高压模板。
  - 仍允许少量高阶能力兜底。
- `西风场`
  - 正式引入能力槽压缩，局外可装备能力开始做减法。
  - 高阶 run 的专属奖励比前两档更重要。
- `北风场`
  - 最高档，能力槽和起始工具都最紧。
  - 专属奖励质量提升，但惩罚更明显，Boss 压力也最高。

## 4. 局外高阶配置

局外新增只对高阶生效的配置面板，存放在 `/games/hulebu` 壳层本地存档里，不污染普通局外升级。

建议结构：

- `equippedAscensionLoadout`
  - 当前装备的高阶能力 key 列表。
- `unlockedAscensionPerks`
  - 已解锁的高阶能力池。

本轮不做复杂树状解锁。先用少量固定能力，重点验证“周目限制”和“局外可装备能力”之间的拉扯。

## 5. 高阶能力与专属奖励

高阶能力分两层：

- `局外可装备能力`
  - 开局前在高阶配置面板选择。
  - 例如：起始额外一次丢弃、Boss 额外铜钱、胡后额外清河、首个高压词缀减轻。
- `高阶专属奖励`
  - 只在高阶 run 的奖励节点里出现。
  - 与当前已装备能力联动，形成构筑分支。

本轮不改通用 `rewards.json`。高阶专属奖励先放在试玩页内部常量和壳层展示逻辑里，避免把普通主线奖励池搅乱。

## 6. 限制规则

不同高阶档至少需要控制这些维度：

- `能力槽数量`
  - 可装备高阶能力的上限。
- `起始工具`
  - 高阶档越高，起始 `洗牌 / 撤回 / 丢弃` 越少。
- `洗牌权限`
  - 高阶档可直接禁用或降低洗牌。
- `奖励衰减`
  - 关后铜钱或高阶奖励收益降低。
- `Boss 压力`
  - 高阶档对第 10 / 20 关和无尽 Boss 有额外要求或更紧目标。

## 7. 实现口径

- 外层壳层负责：
  - 四档高阶入口和解锁链。
  - 高阶配置面板。
  - 高阶能力本地存档。
  - 启动 iframe 时透传高阶档位、装备能力和限制参数。
- 内层试玩页负责：
  - 解析高阶档位和装备能力参数。
  - 按高阶档位调整工具、牌山、压力和奖励。
  - 渲染高阶 HUD 文案、限制文案和专属奖励。

## 8. 测试

- `apps/web` 测试锁定：
  - 四档高阶名称。
  - 高阶配置面板。
  - 局外高阶能力字段。
  - 高阶能力/奖励相关 UI 文案。
- `packages/shared` 文本测试锁定：
  - 内层 HTML 具备四档高阶常量。
  - 能解析高阶局外能力参数。
  - 高阶专属奖励与能力槽限制相关逻辑入口存在。

## 9. 风险控制

- 高阶能力先做小池，不一次性把长期能力系统全展开。
- 高阶专属奖励先内建在试玩页，不立刻抽成共享奖励配置。
- 普通模式、无尽、每日继续沿用现有局外升级，不被高阶配置面板反向影响。
