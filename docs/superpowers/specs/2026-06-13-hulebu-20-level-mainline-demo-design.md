# 胡了卜 20 关完整主线 Demo 设计

- 日期：2026-06-13
- 任务：T166
- 状态：进入实现

## 1. 目标

把当前站内默认玩家 Demo 从 10 关扩展为 20 关主线，让玩家能在 `/games/hulebu` 玩到一个有前半段教学、后半段压力爬坡和终章 Boss 的完整 run。

## 2. 玩家体验

- 第 1-4 关继续承担 `碰 / 吃 / 杠 / 胡` 教学。
- 第 5-9 关维持当前朋友试玩的逐步升压。
- 第 10 关保留终局试炼，作为前半段小 Boss。
- 第 11-19 关进入后半段主线，牌量、堆叠、遮挡和奖励选择压力逐步提高。
- 第 20 关显示 `胡了卜王`，使用更明确的 Boss 目标，作为当前 HTML 完整主线终点。

## 3. 关卡和奖励

- 默认可玩关卡数：20。
- 奖励节点：第 3、6、9、13、16、19 关后。
- 第 20 关通关后不再继续发普通奖励，进入主线完成结算。
- 20 关配置优先复用已有 `levels.json` 骨架；HTML Demo 只补玩家侧 difficulty profile 和终章 Boss 显示逻辑。

## 4. 范围边界

本任务只做主线完整化，不做局外升级闭环。局外首页、铜钱持久资产、升级消费、无尽、每日和成就仍按 T165 后续任务推进。

## 5. 验收标准

- 默认 Demo UI 显示 20 关总进度。
- 自动化测试能验证 playable count、奖励 checkpoint 和第 20 关 Boss。
- 第 20 关 Boss 目标来自配置或明确 helper，不被后半段 difficulty profile 屏蔽。
- 静态站内 Demo 与源 HTML 逻辑一致。
- 桌面端和 390px 移动端浏览器检查无底部遮挡、按钮挤压或明显文本不可读问题。
