# 胡了卜局外首页和结算面板设计

## 背景

T166 完成后，`/games/hulebu` 已具备完整 20 关主线和第 20 关 `胡了卜王` Boss，但站内体验仍是“打开即牌桌”。这会让完整游戏的局外感、回合感和长期成长入口缺位。

T167 的目标不是直接做外置升级数值，而是先把完整体验版的外壳立起来：先看到局外页，再进入主线，结束后回到结算与局外。

## 目标

1. `/games/hulebu` 默认显示局外首页。
2. 局外首页展示：
   - `开始挑战`
   - `继续本轮`
   - `升级`
   - `图鉴`
   - `无尽`
   - `每日`
3. `升级 / 图鉴 / 无尽 / 每日` 第一版允许展示为壳层或锁定入口，不要求真实内容。
4. 主线继续复用现有 `/games/hulebu-demo/index.html` iframe。
5. 通关或失败后进入站内结算面板，再回到局外页。
6. 局外页显示铜钱累计预览，但本任务不开放升级消费。

## 体验定义

### 1. 局外首页

- 默认视图不再直接落到 iframe。
- 顶部显示 `胡了卜`、当前局外铜钱、主线进度摘要。
- 中央区域提供主线入口卡和模式入口。
- `升级` 显示 3 项后续能力预览：
  - 备用槽
  - 满槽护符
  - 初始道具
- `无尽 / 每日 / 图鉴` 以锁定或待开放方式展示。

### 2. 开始与继续

- 点击 `开始挑战` 新建一轮主线 run。
- 如果当前 shell 生命周期内已有未结算 run，可显示 `继续本轮`。
- 玩家可以从外层壳返回局外，但 run 状态仅要求在当前页面生命周期内可继续，不要求刷新后仍保留。

### 3. 结算

- 20 关通关后：展示 `主线通关` 结算。
- 中途失败后：展示 `本轮失利` 结算。
- 结算面板至少显示：
  - 结果标题
  - 到达关卡
  - 本轮铜钱
  - 已选奖励数
  - 累计局外铜钱
- 结算后提供：
  - `再来一轮`
  - `返回局外`

## 技术方案

### Web 壳层

- `apps/web/src/modules/games/hulebu/HulebuGamePage.tsx` 升级为 client component。
- 由 Web 壳层维护三种主状态：
  - `lobby`
  - `playing`
  - `settlement`
- 局外铜钱和最近一次结算可写入浏览器本地存储，作为 T168 前的局外预览。

### iframe 通信

- 静态 Demo 增加 `embed=shell` 模式：
  - 隐藏内层顶部条，避免和外层壳重复。
  - 允许向父页面发送运行事件。
- 事件最小集合：
  - `hulebu:run-progress`
  - `hulebu:run-complete`
  - `hulebu:run-failed`
- 事件负载至少包含：
  - `sessionKey`
  - `levelOrder`
  - `coins`
  - `pickedRewards`
  - `summary`

## 不做

- 不做局外升级消费逻辑。
- 不做 3 项升级真实生效。
- 不做无尽、每日、图鉴真实页面。
- 不做登录、云存档、多端同步。
- 不改 Cocos 正式工程。
