# 胡了卜高阶周目第一版设计稿

## 1. 背景

T172 已补完成就图鉴第一版，`/games/hulebu` 现在已经有主线、结算、升级、无尽、每日和图鉴入口，但“通关后的更高难度轮回”仍停留在玩法文档里。T173 的目标是先把高阶周目做成可开始、可理解的第一版。

## 2. 范围

本任务只做高阶周目第一版：

- 局外页出现高阶周目入口与解锁状态。
- 至少支持 2 档周目，例如 `东风场` 和 `南风场`。
- 进入后仍复用现有 20 关主线结构。
- 外层和内层都能显示当前周目与当前词缀/限制。
- 词缀第一版只做少量稳定、可解释的限制。

不做完整高阶事件扩容、不做完整 Boss 试炼第二版、不做云同步、排行榜、付费、广告或 Cocos 正式工程追平，也不改 `levels.json`、`rewards.json`、每日/无尽规则和升级价格。

## 3. 解锁与交互

- 默认先锁定高阶周目。
- 当玩家完成一轮主线通关后，解锁 `高阶周目 1`。
- 第一版允许在局外面板里查看：
  - 当前已解锁到哪一档
  - 每档的名称
  - 每档的主要限制
- 点击开始后，iframe 带入周目参数。

## 4. 周目口径

第一版建议采用：

- 周目 1：`东风场`
  - 作为已通关后的第一档，限制较轻。
  - 词缀示例：奖励铜钱减少、Boss 目标更紧。
- 周目 2：`南风场`
  - 在周目 1 通关后解锁。
  - 词缀示例：禁洗牌、起始道具减少。

第一版不做复杂随机词缀池，先用固定词缀集保证可读性。

## 5. 数据

外层本地存档新增：

- `bestAscensionLevel: number`

用于记录已解锁的最高周目档位。

shell 消息 payload 新增：

- `ascensionLevel?: number`
- `ascensionName?: string | null`

## 6. 测试

- Web 测试锁定高阶周目入口、周目文案、周目字段和代表性词缀。
- 原型测试锁定周目参数解析、HUD 周目显示和至少两条固定词缀。
- `/games/hulebu` 桌面端和 390px 移动端都要能看到周目入口并进入带周目参数的牌桌。
