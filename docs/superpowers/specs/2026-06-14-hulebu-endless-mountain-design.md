# 胡了卜无尽牌山第一版设计稿

## 1. 背景

T166-T169 已把网页 Demo 推到完整主线的第一阶段：20 关主线、局外首页、结算面板、铜钱资产、3 项局外升级和路线型奖励池都已可用。T170 的目标是补出主线之后的第一个长期挑战入口，让玩家不只停在“打完第 20 关”。

## 2. 范围

本任务只做无尽牌山第一版：

- 局外页 `无尽` 面板从占位改为可开始。
- 无尽从第 21 层开始。
- iframe 使用 `mode=endless&startLayer=21` 进入无尽模式。
- 外层壳持久化本地最高无尽层。
- 结算面板显示本次到达层数和历史最高层。

不做每日、成就、高阶周目、云存档、排行榜、付费、广告、Cocos 正式工程追平，也不改 20 关主线配置和奖励配置。

## 3. 交互

局外页保留 `开始挑战` 作为主线入口，并在无尽面板新增 `开始无尽`。玩家进入无尽后，外层顶部摘要显示“无尽进行中”和当前层数。失败或主动重开后，结算面板按本次层数更新本地最高层。

主线通关仍结算为“主线通关”。无尽失败结算为“无尽结算”，不把无尽当作主线通关。第一版不要求无尽有终点。

## 4. 内层原型

HTML 原型新增 `runMode` 概念：

- `mainline`：现有 20 关主线。
- `endless`：从第 21 层开始循环生成层数。

无尽不新增配置文件。它复用已有 20 个关卡和密集牌山生成器，按层数映射到后半段压力 profile，并通过 seed 加入层数，保证每层有变化。第 5 层倍数给小 Boss 目标，第 10 层倍数给大 Boss 目标；第一版复用现有 boss goal 结构。

## 5. 数据

外层本地存档继续使用 `dreamchasers:hulebu-shell:v1`，新增字段：

- `bestEndlessLayer`: number

运行中消息 payload 新增：

- `runMode`: `"mainline" | "endless"`
- `endlessLayer`: number

老存档没有 `bestEndlessLayer` 时按 0 处理。

## 6. 测试

- Web 测试锁定 `开始无尽`、`bestEndlessLayer`、`runMode=endless`、`mode=endless`、`startLayer=21`。
- 原型测试锁定 `ENDLESS_START_LAYER = 21`、`runMode: "mainline"` 默认值、URL 参数解析、无尽层数 helper、无尽奖励/目标/下一层逻辑。
- 内联脚本必须通过 `node --check`。
- `/games/hulebu` 桌面端和 390px 移动端都要能看到无尽入口并进入牌桌。
