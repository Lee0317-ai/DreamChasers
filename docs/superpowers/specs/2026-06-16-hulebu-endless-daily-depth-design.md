# 胡了卜无尽和每日深度化设计

- 日期：2026-06-16
- 任务：T180
- 负责人：Lee

## 1. 背景

无尽和每日已经有入口，但目前都还是“主线后半段再包一层”的第一版。完整版路线里明确要求它们承担长期曲线、周期 Boss、每日词缀、每日奖励和连续参与目标，所以这一轮要补的是“模式 identity”，而不是只多加几层数字。

## 2. 本次目标

1. 无尽模式出现更明确的章节节奏与周期 Boss。
2. 每日模式出现可感知的今日词缀和每日奖励。
3. 外层 `/games/hulebu` 能看到每日连续参与和无尽章节摘要。
4. 继续复用现有存档与 payload，不新增 Prisma 字段。

## 3. 设计口径

### 3.1 无尽模式

- 在现有 `第 21 层起步` 基础上，加 `章节` 概念：
  - 每 5 层为一个 Boss 节点。
  - 每 10 层为一个章节切换点。
- 章节文案示例：
  - 第 21-30 层：试手段
  - 第 31-40 层：压台段
  - 第 41+ 层：死斗段
- 周期 Boss 不只显示 `Boss`，还显示 `章节 Boss` 或 `压台 Boss` 提示。

### 3.2 每日模式

- 每日根据 `dailySeed` 派生一个 `今日词缀`。
- 每日词缀先只做文案级和轻量参数级变化，不引入新 effect 系统。
- 每日奖励继续复用铜钱与奖励节点，但补一个 `今日奖励摘要`。
- 外层新增 `dailyStreak`，用本地连续日期记录连续参与天数。

### 3.3 外层壳层

- 新增每日显示：
  - 今日词缀
  - 连续参与天数
  - 今日奖励摘要
- 新增无尽显示：
  - 当前章节
  - 下一次章节 Boss 提示

## 4. 不做

- 不做真实排行榜、每周榜或全球共享 seed 排名。
- 不做新的局外货币或每日商店。
- 不改 Cocos 和 Prisma。
- 不把每日词缀扩成完整词缀系统。
