# 胡了卜成就图鉴扩容设计

- 日期：2026-06-16
- 任务：T179
- 负责人：Lee

## 1. 背景

T172 已把 `/games/hulebu` 的图鉴从占位改成第一版本地成就页，但当前仍只有 8 条基础成就和平铺卡片。随着 T176/T177/T178 完成高阶、Boss 和事件第二版，图鉴需要同步扩为更完整的长期目标入口，否则这些系统仍像分散功能，不像一套完整内容层。

## 2. 本次目标

1. 把图鉴从“8 张卡”扩成“分类摘要 + 成就列表”的第二版。
2. 新增 Boss、事件、高阶和路线目标，补齐 T176/T177/T178 已有系统信号。
3. 保留一部分隐藏目标，让图鉴有揭示感，而不是把全部攻略写在脸上。
4. 继续只使用现有壳层存档与结算信号，不引入新后端字段或玩法规则。

## 3. 设计口径

### 3.1 成就分层

- 基础进度：主线、无尽、每日、升级。
- 进阶挑战：高阶周目、Boss、事件、路线构筑。
- 隐藏目标：只显示“未揭示”与简短模糊提示，解锁后再展开真实名称和描述。

### 3.2 第二版新增成就建议

- Boss：
  - `boss-hulebu-king` 继续保留。
  - 新增高阶 Boss 相关目标。
- 事件：
  - 使用 `specialEventReview` 信号识别是否经历过稀有/高阶/构筑联动事件。
- 高阶：
  - 识别 `bestAscensionLevel`，新增到达西风场 / 北风场之类的成就。
- 路线：
  - 使用 `lastSettlement.pickedRewards` 和高阶构筑摘要做轻量路线成就，不回头改原型奖励 payload。

### 3.3 存档兼容

- 继续复用 `achievements: Record<string, string>`。
- 旧存档 hydration 时继续按已有字段补算。
- 新增成就只依赖已经存在的本地字段：
  - `bestEndlessLayer`
  - `dailyBestLevels`
  - `bestAscensionLevel`
  - `upgrades`
  - `lastSettlement`
  - `lastSettlement.bossReview`
  - `lastSettlement.specialEventReview`

## 4. UI 口径

- 图鉴顶部改成：
  - 总解锁数
  - 当前主分类进度
  - 下一条未解锁目标
- 成就列表按分类分段，而不是完全平铺。
- 隐藏目标在未解锁时显示：
  - 标题：`未揭示目标`
  - 描述：模糊提示
  - 元信息：`继续推进 Boss / 事件 / 高阶`

## 5. 不做

- 不补事件词条详情库。
- 不补独立 Boss 档案页。
- 不发铜钱或道具奖励。
- 不改 HTML 原型和静态 Demo。
- 不改后端和 Prisma。
