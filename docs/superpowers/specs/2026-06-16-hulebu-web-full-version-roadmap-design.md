# 胡了卜网页版完整版优先路线设计

- 日期：2026-06-16
- 任务：T175
- 状态：路线已确认，进入后续 Web 内容实现拆分

## 1. 路线决策

后续不先做 Cocos 追平，也不先补音乐、美术资源。胡了卜接下来先把网页版完整开发到内容、系统、数值和长期目标稳定，再按冻结规格追平 Cocos，最后补音乐、美术、动效和发布资源。

这个决策不否定 Cocos 正式工程。Cocos 仍是后续正式发布主线，但它应该承接稳定后的 Web 完整版，而不是追着仍在变化的网页 Demo 反复改。

## 2. 当前 Web 已完成

- 20 关主线和第 20 关终章 Boss 第一版。
- 局外首页、继续本轮、结算面板和返回局外。
- 局外铜钱资产和 `备用槽 / 满槽护符 / 初始道具` 3 项升级。
- 路线型奖励池第一版，覆盖吃流、碰流、杠流、胡流、道具流和信息流。
- 无尽牌山第一版。
- 每日牌局第一版。
- 成就图鉴第一版。
- 高阶周目第一版，已有东风场和南风场入口。
- 登录账号长期进度续层。

## 3. 相对完整版仍缺的内容

- 高阶周目还只是第一版：西风场、北风场、能力槽限制、词缀组合、解锁节奏和高阶专属奖励仍未成型。
- Boss 试炼仍是 Demo 第一版：第 10 关终局试炼和第 20 关 Boss 已能玩，但缺 Boss 目标池、阶段变化、试炼奖励品质和高阶 Boss 变体。
- 特殊事件池偏小：当前只有少量关前事件，缺事件稀有度、正负事件、路线联动、事件图鉴和高阶事件。
- 成就图鉴偏薄：首批成就能记录长期进度，但缺分层目标、隐藏目标、Boss/事件/路线成就和奖励反馈。
- 无尽和每日深度不足：无尽缺长期曲线、周期 Boss、赛季化目标；每日缺每日词缀、每日奖励和连续参与目标。
- 路线奖励和局外能力还不够完整：当前奖励池能表达路线，但缺路线连携、永久能力槽、局外能力组合和高阶限制下的构筑变化。
- 数值和平衡仍未冻结：20 关后半段、无尽层数曲线、每日难度、高阶词缀压力、局外升级价格和铜钱产出都需要统一调平。
- Web 发布体验还未封版：新手引导、返回局外、失败恢复、存档合并提示、移动端长时游玩体验和错误兜底还需要一起验收。

## 4. 后续阶段

### 阶段 A：Web 内容系统补完

优先在 Web 里补高阶周目、Boss 试炼、事件池、成就图鉴、无尽/每日、路线奖励和局外能力。每个任务都必须能在 `/games/hulebu` 被玩家直接体验，而不是只更新内部文档。

### 阶段 B：Web 数值和内容冻结

当 Web 内容覆盖完整版目标后，集中做 20 关主线、无尽、每日、高阶、局外经济和奖励池平衡。冻结后输出 Cocos 可追平的规则、配置和表现清单。

### 阶段 C：Cocos 追平

Cocos 在 Web 冻结后追平，不先追当前仍变化的 Demo。追平范围包括主线、局外循环、奖励、Boss、事件、无尽、每日、成就、高阶和账号进度口径；表现层继续消费共享规则和配置，不复制临时 DOM 状态。

### 阶段 D：音乐、美术、动效和发布资源

音画资源等玩法和界面口径稳定后再接。优先级为正式牌面 prefab、奖励卡和 Boss/事件 UI、关键动效、音效反馈、背景音乐、图标和发布截图。
