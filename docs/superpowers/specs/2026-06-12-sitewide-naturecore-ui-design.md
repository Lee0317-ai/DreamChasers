# 全站 Naturecore UI 统一设计稿

日期：2026-06-12  
状态：已确认并实施  
对应任务：T158  
选定方向：C - Hybrid Portal

## 1. 目标

将 T157 已确认的账号中心 Naturecore 动态深色风格扩展到 DreamChasers 全站。首页允许更强的背景、传送门和沉浸式视觉；内页保持深色控制台、玻璃面板、金色/青色点缀和鼠标反馈，优先保证工具效率和信息可读性。

## 2. 设计原则

- 首页负责记忆点：可以使用森林、月环、传送门、粒子、远景层次等背景语言。
- 内页负责效率：工具频道、游戏频道、登录注册、账号中心使用统一深色控制台组件，不让背景干扰操作。
- 动效只增强反馈：鼠标跟随微光、卡片 hover 光扫、标题 hover 发光、按钮轻微浮起，不做影响阅读的持续大幅动画。
- 8px 圆角为主：卡片、按钮、输入框保持克制；pill 状态标签可使用圆角胶囊。
- 不改业务：本轮只改展示层和页面结构，不动 AI Gateway、积分、Prisma、工具核心逻辑或 TimePick 外部仓库。

## 3. 页面范围

### 首页 `/`

首页使用最强视觉：

- 全屏深色 Naturecore 背景。
- 中央或偏中传送门/月环主视觉。
- 工具站和游戏馆作为两个可点击入口，但从左右硬切换升级为沉浸式双入口。
- 登录/注册入口保留在右上角，使用半透明玻璃按钮。
- 鼠标移动时背景光晕和入口卡片产生轻微响应。

### 工具频道 `/tools`

工具频道使用控制台式频道页：

- 顶部 hero 有轻量背景纹理，不使用强森林图。
- 搜索框、筛选 tabs、工具卡片统一深色玻璃质感。
- PDF、AI 修图、TimePick 等卡片保留清晰功能说明和状态标签。
- 只改频道页外层和卡片，不深入改每个工具工作台核心逻辑。

### 游戏频道 `/games`

游戏频道与工具频道同系统，但可以更偏娱乐：

- 同样使用深色玻璃卡片和金色/青色点缀。
- 允许比工具页更强的发光和背景纹理。
- 胡了卜入口继续清晰可点击，不改游戏 runtime。

### 认证页 `/login`、`/register`、找回密码

认证页使用轻量版本：

- 深色背景和右侧/后景微光。
- 表单面板使用玻璃质感。
- 按钮、输入框、错误提示统一 Naturecore 变量。
- 保持表单布局简洁，不加入复杂背景图。

### 账号中心 `/account/**`

沿用 T157 已完成风格，仅做少量变量和导航一致性校正：

- 保持无森林背景。
- 保持控制台、数据面板和 AI 能力卡的清晰度。
- 与全站 nav、按钮、卡片变量一致。

### 工具工作台

PDF 工具箱、AI 修图工具本轮只做外壳统一：

- 页面背景、顶部导航、主要面板、按钮状态统一到新视觉。
- 不重排复杂操作区，不改变上传、编辑、轮询、结果展示逻辑。
- 如果后续要深度改 PDF 或 AI 修图工作台，单独拆任务。

## 4. 视觉系统

### 色彩

- 背景：深蓝黑 / 深青黑。
- 主强调：旧金色，用于品牌、标题、推荐、主按钮。
- 辅强调：青色，用于 AI、搜索、状态光、hover 光。
- 成功：低饱和绿色。
- 警告：金色。
- 危险：玫红。

### 字体

- 标题：Georgia / Times New Roman / 系统 display fallback，形成 mythic 质感。
- 正文：系统 sans，保证中文阅读稳定。
- 数字和状态：mono 字体，适合积分、模型、统计。

### 组件

- 全站按钮：玻璃底 + 金色边框，hover 轻微浮起。
- 卡片：8px 圆角、半透明深色 surface、局部鼠标光晕、hover 光扫。
- 输入框：深色透明底、青色 focus ring。
- 导航：固定顶部玻璃条，当前频道用金色或青色状态。
- 标签：pill，用颜色语义区分可用、推荐、Beta、后续。

## 5. 实现边界

第一轮实现优先：

- `HomeExperience` 首页沉浸视觉。
- `AppHeader` 和全站 nav 统一。
- `ChannelPage`、`PortalCard`、`PortalModal` 统一。
- 认证页样式统一。
- PDF 工具箱和胡了卜外层兼容性检查。
- 账号中心保留 T157，不做大改。

第一轮不做：

- 不引入外部图片依赖作为必需资源。
- 不新增复杂 Three.js 或大型视频背景。
- 不重做 AI 修图 canvas 工作区。
- 不重写 PDF 业务组件。
- 不改变页面路由、登录流程或 API。

## 6. 验收标准

- 首页在桌面端第一屏有明显 Naturecore 记忆点，并能清楚进入工具站和游戏馆。
- 工具、游戏、认证、账号页面视觉统一，不像多个站拼在一起。
- 移动端无横向溢出，按钮和文本不挤压。
- 账号中心 AI 页面继续可用，T157 动效不丢失。
- `npm run typecheck -w apps/web` 通过。
- `npm run build -w apps/web` 通过。
- 相关测试通过。
- 浏览器检查 `/`、`/tools`、`/games`、`/login`、`/account/ai/credits`。

## 7. 风险与处理

- 强背景可能影响工具效率：只在首页使用强背景，内页收敛为控制台外壳。
- 全站 CSS 可能误伤工具工作台：通过页面级 class 和已有组件类分层覆盖，避免全局粗暴改所有元素。
- 现有工作区未提交改动较多：只在 T158 允许范围内增量修改，不回滚已有文件。
- `git diff --check` 可能继续被 Prisma generated 文件阻塞：记录全量结果，并对 T158 涉及文件做限定检查。
