# 胡了卜 Demo 完整体验版推进方案设计

- 日期：2026-06-13
- 任务：T165
- 状态：已确认方向，进入后续实现拆分

## 1. 目标

把当前 `/games/hulebu` 的 10 关朋友试玩 Demo 推进为“完整体验版”的路线，而不是继续做零散补丁。完整体验版第一阶段不追求最终商业化和全部长期模式，而是先让玩家感到这是一个完整游戏：有主线、有阶段终点、有局外页面、有升级目标、有后续模式入口。

## 2. 当前 Demo 已完成

- 10 关朋友试玩。
- 第 1-4 关教学 `碰 / 吃 / 杠 / 胡`。
- 第 5-10 关渐进牌量和高压模板。
- 8 格主槽、有限牌河、明牌区、补杠、明杠开山和胡牌震落。
- 牌山记牌器、听牌提示、震落牌平铺、遮挡点击修复。
- 残局收官第一阶段：弃牌通关和选作牌引。
- 第 6、8、10 关特殊事件第一版。
- 第 10 关终局试炼：`杠 1 / 胡 1 / 积分 180`。
- 站内 `/games/hulebu` iframe 发布入口。

## 3. 完整方案仍缺口

完整设计中还没有进入 Demo 的核心内容包括：

- 默认玩家 Demo 未开放 20 关主线。
- 第 11-20 关没有玩家侧节奏和平衡体验。
- 第 20 关 Boss 没有在站内 Demo 中作为终章出现。
- 没有局外首页、继续挑战、升级入口和模式入口。
- 铜钱只是 run 内数字，还没有局外资产和升级消费闭环。
- 局外升级未落地：备用槽、满槽护符、初始道具次数。
- 现有奖励池偏轻，没有形成足够清楚的吃流、碰流、杠流、胡流、道具流和信息流。
- 无尽牌山、每日牌局、成就图鉴和高阶周目仍在设计文档阶段。
- Cocos 正式工程已有骨架和首条链路，但未承接当前 HTML Demo 的完整体验内容。

## 4. 推进原则

第一原则：先完整主线，再长期模式。

当前最该补的是 20 关主线和局外成长壳。无尽、每日、成就和高阶周目都依赖一套可重复挑战的基础主线。如果 20 关还没有跑顺，长期模式只会把问题复制多份。

第二原则：HTML Demo 继续负责快速验证完整体验，Cocos 负责正式发布承接。

HTML Demo 可以先验证局外页、20 关节奏、升级和长期入口；Cocos 不应在玩法仍变化时追赶所有功能。等 HTML 完整体验稳定后，再把同一套规则和配置迁移到 Cocos 正式版。

第三原则：每个阶段都要能被朋友试玩。

每一步交付后都应能打开 `/games/hulebu` 玩到一个更完整的版本，而不是只有文档或内部代码。

## 5. 阶段路线

### 阶段 A：20 关完整主线体验

目标是把默认 Demo 从 10 关扩为 20 关，并让第 20 关成为终章 Boss。

范围：

- 默认玩家页开放 20 关。
- 第 1-10 关保留当前朋友试玩节奏。
- 第 11-19 关使用已有配置骨架，套用渐进难度 profile。
- 第 20 关启用 `胡了卜王` 终章 Boss，目标来自配置或轻量 Demo override。
- 奖励节点改为第 3、6、9、13、16、19 关。
- 10 关和 20 关都可以有 Boss/试炼，但第 20 关必须是更明确的终点。

不做：

- 不做无尽、每日、成就。
- 不引入登录和云存档。
- 不改 Cocos。

### 阶段 B：局外首页和升级壳

目标是让玩家看到“这是一个完整游戏”，而不是直接掉进牌桌。

范围：

- Demo 内新增开始页或 run 面板。
- 展示 `开始挑战 / 继续本轮 / 升级 / 图鉴 / 无尽 / 每日`。
- `无尽 / 每日 / 图鉴` 第一版可锁定展示解锁条件。
- 铜钱从 run 内数字提升为局外累计资产。
- 通关或失败后进入结算面板，再回到局外页。

### 阶段 C：局外升级最小闭环

目标是让铜钱有用途。

第一批升级只做 3 项：

| 升级 | 效果 |
| --- | --- |
| 备用槽 | 每局初始备用容错 +1 档 |
| 满槽护符 | 每轮获得一次满槽前保护 |
| 初始道具 | 洗牌、撤回、丢弃初始次数提高 |

主槽仍固定 8 格，不做永久主槽扩容，避免破坏当前已经验证的 8 格胡牌压力。

### 阶段 D：奖励池路线化

目标是让 Roguelike 构筑更明显。

第一版扩展方向：

- 吃流：顺子提示、吃后收益、连续吃奖励。
- 碰流：碰后补牌、碰后积分、碰后明牌联动。
- 杠流：明杠震落、补杠收益、杠后开山强化。
- 胡流：听牌提示增强、胡后清河、胡后震落强化。
- 道具流：洗牌、撤回、丢弃次数和效果变化。
- 信息流：记牌器、透视和目标高亮。

### 阶段 E：长期模式入口

在主线和局外升级稳定后再接：

- 无尽牌山：从第 21 层开始，每 5 层小 Boss，每 10 层大 Boss。
- 每日牌局：每日固定 seed，本地成绩记录第一版。
- 成就图鉴：先做首通、杠次数、胡次数、无洗牌通关、20 关通关等本地成就。
- 高阶周目：南风场、西风场、北风场逐步加入词缀和能力槽限制。
