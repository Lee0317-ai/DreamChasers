# 胡了卜铜钱资产和 3 项局外升级设计

## 背景

T167 已把 `/games/hulebu` 做成完整壳层，但铜钱还只是局外预览。T168 的目标是让这个数字变成真实资产，并让 3 项局外升级买完后，下一轮主线能直接感知到变化。

## 范围

本轮只做 3 项局外升级：

1. `备用槽`
2. `满槽护符`
3. `初始道具`

不恢复主槽扩容。主槽仍固定 8 格。

## 升级定义

### 1. 备用槽

- Lv.0：无额外局外备用槽
- Lv.1：主线 run 初始 `reserveLimit +1`
- Lv.2：主线 run 初始 `reserveLimit +2`

### 2. 满槽护符

- Lv.0：无额外局外护符
- Lv.1：主线 run 初始 `shields +1`
- Lv.2：主线 run 初始 `shields +2`

### 3. 初始道具

- Lv.0：使用当前主线默认道具次数
- Lv.1：主线 run 初始 `shuffle / undo / discard` 各 `+1`
- Lv.2：主线 run 初始 `shuffle / undo / discard` 各 `+2`

## 成本

本轮采用固定两档成本：

| 升级 | Lv.1 | Lv.2 |
| --- | --- | --- |
| 备用槽 | 80 | 240 |
| 满槽护符 | 160 | 480 |
| 初始道具 | 120 | 360 |

说明：
- 备用槽和护符成本直接沿用既有玩法文档。
- 初始道具成本本轮按中间档位设定，低于护符、高于备用槽，作为第一版平衡占位。

## 资产规则

- 通关或失败后的结算铜钱进入局外资产。
- 局外升级消费直接从局外资产扣除。
- 局外资产和升级等级一起存入浏览器本地存储。
- 刷新页面后，局外资产和升级等级保留。

## 技术方案

### Web 壳层

- 在 `HulebuGamePage.tsx` 中新增：
  - `bankedCoins`
  - `upgrades`
  - `activeLoadoutSummary`
- `startRun()` 时，把升级换算成 iframe URL 参数。

### iframe 参数桥接

新增 URL 参数：

- `reserveBonus`
- `shieldBonus`
- `toolBonus`

Demo 初始化时读取这些参数，并在 `loadLevel()` 中叠加到：

- `reserveLimit`
- `shields`
- `tools.shuffle / tools.undo / tools.discard`

## UI 预期

- `升级` 面板不再只是说明文本，而是有真实升级卡和购买按钮。
- 卡片至少显示：
  - 名称
  - 当前等级
  - 下一档效果
  - 当前价格
  - 购买按钮
- 买不起时按钮禁用并提示铜钱不足。
- 已满级时显示 `已满级`。

## 不做

- 不做局外升级退款或重置。
- 不做跨设备同步。
- 不开放 `vision` 道具局外升级。
- 不做更多局外成长树。
