# AI 面试助手

**模块 slug**：`ai-interview-coach`
**当前状态**：规划评估
**任务编号**：T106
**负责人**：Lee

## 模块定位

AI 面试助手是网页工具频道下的 AI 能力工具。用户输入岗位 JD、简历和面试参数后，生成双视角面试作战包，并可进入虚拟面试模式进行文本问答练习，最后下载 HTML 复盘报告。

## 用户入口

- 面试者：准备面试、练习回答、发现简历薄弱点。
- 面试官：准备结构化问题、追问链和评分卡。

## MVP 能力

- JD 和简历文本输入。
- 简历图片上传规划。
- 面试参数配置。
- 面试官 / 面试者 / 双视角输出。
- HTML 面试作战包下载。
- 文本虚拟面试。
- 面试复盘 HTML 下载。
- 后续增强：简历优化建议、专业领域实战例子和行业用法说明。

## 暂不做

- 实时语音面试。
- 简历优化改写。
- 用户账号和历史报告库。
- 批量候选人筛选。
- ATS 或企业招聘系统接入。
- 自动录用、淘汰或候选人排名。
- 真实面试中的实时作弊辅助。
