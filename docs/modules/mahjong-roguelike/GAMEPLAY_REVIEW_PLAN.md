# 麻将 Roguelike 消除游戏玩法方案

**版本**：团队评审稿 v0.1  
**日期**：2026-05-22  
**关联任务**：T041  
**用途**：供团队评审玩法是否成立、补足缺口，并作为后续开发计划拆分前的玩法基线。

## 1. 一句话定位

这是一款 `羊了个羊式堆叠消除 + 轻麻将吃碰杠 + Roguelike 构筑 + 局外养成` 的休闲策略小游戏。

第一版不做完整麻将算法，不做多人对战，不做真实听牌和复杂番型。麻将感来自：

- 牌面：`万 / 条 / 筒` 三类基础牌。
- 动作：玩家手动发动 `吃 / 碰 / 杠`。
- 决策：等杠还是先碰、做顺子还是清槽、是否保留孤张。
- 氛围：按钮点燃、金红火焰、牌谱记牌器、胡牌目标和风场命名。

## 2. 设计目标

| 目标 | 说明 |
| --- | --- |
| 停留时长 | 一局内有多关、奖励、构筑和风险选择 |
| 回访 | 体力、每日牌局、无尽层数和成就图鉴 |
| 策略感 | 手动吃碰杠、余牌判断、孤张处理、构筑路线 |
| 可落地 | 不依赖 AI 模型，不依赖网络实时生成，小程序本地可运行 |
| 可扩展 | 主线 20 关之后接无尽、高阶周目、每日、成就 |

## 3. 核心循环

```text
开始一轮牌局
-> 消耗体力
-> 进入第 1 小关
-> 点击可见麻将牌入槽
-> 判断并手动发动 吃 / 碰 / 杠
-> 获得局内积分
-> 清空牌面或完成目标过关
-> 获得铜钱
-> 从 3 个局内奖励中选 1 个
-> 进入下一小关
-> 失败后局内能力清空，已结算铜钱保留
-> 回到局外升级或再次挑战
```

这里的“一轮 run”指从开局进入连续小关，到失败或完成目标为止的一次完整挑战。普通主线建议一轮包含 8-12 个小关节奏，最终主线目标是打穿 20 关。

## 4. 基础牌局规则

### 4.1 点击和入槽

- 只要牌没有被上层牌覆盖，就可以点击。
- 点击后牌进入底部主槽。
- 入槽动画期间锁定输入，不能继续点牌、点槽位或点道具。
- 牌入槽后不能手动撤销，只能使用 `撤回` 道具。
- 不加入传统麻将接龙的左右开放规则，第一版只看上层遮挡。

### 4.2 手动组合

系统只检测组合，不自动消除。玩家必须选择组合并点击按钮发动。

| 动作 | 规则 | 示例 | 定位 |
| --- | --- | --- | --- |
| `吃` | 同花色连续 3 张 | 2条 3条 4条 | 灵活、顺子、低收益 |
| `碰` | 同花色同点数 3 张 | 5万 5万 5万 | 稳定、清槽、中收益 |
| `杠` | 同花色同点数 4 张 | 8筒 8筒 8筒 8筒 | 高风险、高收益 |

按钮状态：

- 默认灰色不可用。
- 满足条件后变为金红色，字上冒火。
- 多个组合同时存在时显示候选数量和候选内容。
- 点击发动后立即执行，不做二次确认。

### 4.3 多组合冲突

同一槽位可能同时存在 `吃 / 碰 / 杠`。

例如：

```text
3万 4万 5万 5万 5万
```

此时：

- `吃` 可以消 `3万 4万 5万`。
- `碰` 可以消 `5万 5万 5万`。

玩家自由选择。选择一种后，另一种可能被破坏，这是策略来源，不是错误。

## 5. 槽位和失败

### 5.1 槽位结构

| 类型 | 建议 |
| --- | --- |
| 初始主槽 | 7 |
| 永久主槽上限 | 9 |
| 局内临时主槽上限 | 10 或 11 |
| 永久备用槽上限 | 2 |

槽位是局外养成核心，不只是失败计数器。

基础成长方向：

- 主槽容量。
- 备用槽。
- 满槽护符。
- 初始洗牌、撤回、透视次数。

### 5.2 满槽判定

满槽不等于立刻失败。

```text
主槽满
-> 检测是否有可发动 吃 / 碰 / 杠
-> 有组合则锁定玩家先消除
-> 无组合则进入失败前救场
```

主槽满且存在合法组合时，玩家不能继续点击牌面，必须先处理槽内组合。

### 5.3 失败前救场顺序

```text
组合检测
-> 备用槽自动救场
-> 满槽护符
-> 救场道具窗口
-> 首败保护
-> 失败结算
```

说明：

- `组合检测`：有组合就不失败。
- `备用槽自动救场`：备用槽有空位时，自动把 1 张主槽牌移入备用槽。
- `满槽护符`：优先移除内部死孤张。
- `救场道具窗口`：只展示能改变当前失败状态的道具。
- `首败保护`：每轮第一次真正失败前，随机丢弃主槽 1 张牌。
- `失败结算`：不允许复活。

失败后：

- 本轮局内能力清空。
- 本轮局内积分清空。
- 已经结算到局外账户的铜钱保留。
- 未过关部分不发过关铜钱。

## 6. 孤张规则

孤张只做系统内部判定，不直接给玩家贴标签。

| 类型 | 内部定义 |
| --- | --- |
| 暂时孤张 | 当前槽内无法参与任何 `吃 / 碰 / 杠` 的牌 |
| 死孤张 | 结合记牌器后，未来也没有补牌机会的暂时孤张 |

死孤张不能无限堆积，必须有消化机制：

- 备用槽。
- 换牌。
- 弃牌符。
- 满槽护符。
- 特定关卡豁免。
- 局内能力提供的孤张处理。

玩家不直接看到“死孤张”字样，但能通过余牌、候选组合和道具提示判断风险。

## 7. 牌谱记牌器

页面上方显示本局剩余牌数量，用户侧名称建议为 `余牌`。

默认简版：

```text
余牌  万12  条9  筒15
```

展开后显示 1-9 点数剩余数量。

记牌器统计范围：

- 牌山里未消除的牌。
- 可见但未拿的牌。
- 主槽里的牌。
- 备用槽里的牌。

它和透视的区别：

| 系统 | 告诉玩家 | 不告诉玩家 |
| --- | --- | --- |
| 记牌器 | 还剩哪些牌、数量是多少 | 牌在哪里 |
| 透视 | 隐藏牌大概在哪里 | 全局还剩多少 |

## 8. 道具系统

MVP 三个基础道具：

| 道具 | 效果 | 定位 |
| --- | --- | --- |
| 洗牌 | 重排牌面中未进入槽位的牌 | 调整牌山节奏 |
| 撤回 | 将最近入槽的一张牌放回原位 | 唯一基础撤销方式 |
| 透视 | 显示一层被遮挡牌数秒 | 规划路线，不直接救满槽 |

注意：

- 普通透视不能释放主槽，所以不能单独阻止失败。
- 普通洗牌只重排牌山，不改变已满主槽，也不能单独阻止失败。
- 后续可加入 `弃牌符`，但它是强救场资源，是否进入 MVP 待评审。

## 9. 经济和体力

收益分两层：`局内积分` 和 `铜钱`。

### 9.1 局内积分

局内积分只在当前一轮有效，失败或结束后清空。

获得：

| 动作 | 占位收益 |
| --- | --- |
| `吃` | +10 |
| `碰` | +20 |
| `杠` | +50 |
| 简化胡牌目标 | +80 |

消耗：

- 买洗牌。
- 买撤回。
- 买透视。
- 买弃牌符，后续可开放。
- 刷新局内奖励，后续可开放。

### 9.2 铜钱

铜钱是局外长期资源。

获得：

- 过关奖励。
- 20 关通关。
- 无尽层数结算。
- 成就奖励。
- 每日牌局奖励。
- 后续排行奖励。

用途：

- 升级主槽容量。
- 解锁备用槽。
- 升级满槽护符。
- 解锁或升级初始道具次数。
- 解锁能力卡槽相关系统。
- 购买体力。
- 解锁皮肤、称号、按钮火焰特效。

### 9.3 体力

| 项目 | 建议值 |
| --- | --- |
| 单局消耗 | 5 点体力 |
| 体力上限 | 100 点 |
| 恢复 | 按时间恢复 |
| 购买 | 可用铜钱或付费购买 |

体力只限制正式收益局，不限制新手引导和低成本试玩。

## 10. Roguelike 结构

局内奖励是每过关 `3 选 1`，只在当前 run 内生效。

奖励方向：

- 组合强化：强化吃碰杠收益。
- 花色构筑：围绕万、条、筒做路线。
- 槽位变化：改变主槽或备用槽压力。
- 风险收益：提高难度但提高收益。
- 道具联动：改变洗牌、撤回、透视价值。
- 孤张处理：移除、补牌、换牌或提示孤张。

MVP 可先做 10 个局内奖励：

| 奖励 | 效果 |
| --- | --- |
| 红中火令 | `碰` 后下次 `碰` 额外局内积分 |
| 顺水推舟 | `吃` 后高亮一个接近顺子的牌 |
| 明杠有赏 | `杠` 后随机移除 1 张未遮挡牌 |
| 万字当头 | 万子组合收益提高 |
| 条条生风 | 条子组合后，下次选牌可免费撤回 |
| 筒心聚宝 | 筒子组合额外局内积分 |
| 留一手 | 本局槽位上限 +1 |
| 破釜沉舟 | 槽位 -1，局内积分收益提高 |
| 余火未尽 | 发动组合后短暂提示一个可用按钮 |
| 老雀识路 | 每关开始提示一个组合方向 |

## 11. 永久成长和能力卡槽

永久能力分 4 层：

| 层级 | 是否占能力槽 | 作用 |
| --- | --- | --- |
| 基础成长 | 否 | 降低基础压力，长期成长 |
| 固化能力 | 是 | 决定一轮偏向什么打法 |
| 起局能力 | 是 | 调整开局手感 |
| 道具强化 | 是 | 强化洗牌、撤回、透视、备用槽 |

必须区分：

- `手牌槽位`：底部放牌容量和容错。
- `能力卡槽`：开局前装备永久能力的位置。

高阶周目压缩的主要是能力卡槽，不默认等于砍手牌槽位。

## 12. 模式结构

最终结构：

```text
闯关模式
-> 无尽牌山
-> 高阶周目
-> 每日牌局
-> 成就图鉴
```

### 12.1 闯关模式

- 固定 20 关。
- 第 1-5 关：新手引导和爽感。
- 第 6-10 关：引入目标。
- 第 11-15 关：开始要求构筑。
- 第 16-19 关：高压组合和花色目标。
- 第 20 关：胡牌 Boss 关。

通关解锁：

- 无尽牌山。
- 高阶周目。
- 新局内奖励池。
- 首通徽章和大量铜钱。

### 12.2 无尽牌山

- 20 关后解锁。
- 从第 21 层继续挑战。
- 每 5 层小 Boss，每 10 层大 Boss。
- 层数越高，牌山更厚、目标更苛刻、词缀更多。

### 12.3 高阶周目

建议用风场包装：

| 周目 | 名称 | 特点 |
| --- | --- | --- |
| 0 | 东风场 | 基础难度 |
| 1 | 南风场 | 牌山更厚，目标更多 |
| 2 | 西风场 | 负面词缀和道具限制 |
| 3 | 北风场 | 初始压力和 Boss 更高 |
| 4+ | 雀圣场 | 高压挑战，奖励更高 |

### 12.4 每日牌局

- 每天固定 seed。
- 所有人面对同一牌局。
- 第一版可先只做本地记录。
- 后续可接排行榜。

### 12.5 成就图鉴

成就要绑定特殊打法，不只做次数累计。

示例：

- 首次通关 20 关。
- 一轮发动 10 次 `杠`。
- 连续 5 次同花色组合。
- 不升级槽位通关 20 关。
- 无尽达到第 100 层。
- 不使用洗牌通关 20 关。

## 13. 牌局生成

游戏本体不依赖 AI 模型。牌局通过程序化随机生成。

```text
关卡硬约束
+ 本局随机气质
+ 规则护栏
+ 轻量校验
+ 兜底 seed
```

### 13.1 关卡硬约束

关卡规定边界：

- 总牌数。
- 可用花色。
- 最大堆叠深度范围。
- 目标类型。
- 可出现的牌局气质池。
- 干扰上限。
- 救场下限。
- 最大生成尝试次数。
- 兜底 seed。

### 13.2 牌局气质

每局可随机 1 个主气质，后期可加 0-1 个副气质。

| 气质 | 特征 | 奖励联动 |
| --- | --- | --- |
| 顺风局 | `吃包` 更多 | 吃流、顺子提示 |
| 刻子局 | `碰包` 更多 | 碰流、同点提示 |
| 杠火局 | `杠包` 更多，高积分高风险 | 杠流、残杠处理 |
| 清一色局 | 某一花色明显偏多 | 花色流、清一色 |
| 混花局 | 三花色平均 | 记牌器、信息流 |
| 险张局 | 干扰包更多 | 孤张、备用槽、弃牌符 |
| 补牌局 | 孤张多，但补牌机会也多 | 换牌、补牌、看张听路 |
| 暗山局 | 深层关键牌更多 | 透视、老雀识路 |

气质建议半公开给玩家，例如显示 `本局牌势：杠火局`，但不显示具体比例。

### 13.3 小程序生成口径

```text
读取 level config
-> 生成 seed
-> 抽主气质
-> 生成目标包
-> 生成吃 / 碰 / 杠包
-> 加干扰包
-> 加救场包
-> 打散成具体麻将牌
-> 从布局池选择牌山模板
-> 按最大深度放入多层牌山
-> 轻量校验
-> 不通过则重试
-> 多次失败使用 fallbackSeed
```

主线 20 关必须本地可生成、可兜底、不可依赖网络、不可依赖 AI、不可要求付费道具才能过。

## 14. 新手引导

新手引导不是独立关卡类型，而是覆盖前几局的引导层。

| 步骤 | 开放内容 | 目标 |
| --- | --- | --- |
| 1 | 点击未被覆盖的牌入槽 | 学会可点击规则 |
| 2 | `碰` 按钮点亮 | 学会手动发动 |
| 3 | `吃` 按钮点亮 | 学会顺子 |
| 4 | `杠` 按钮点亮 | 学会四消和高收益 |
| 5 | 多组合候选 | 学会自由选择 |
| 6 | 余牌展开 | 学会判断补牌和孤张风险 |
| 7 | 槽满危局 | 学会救场顺序 |
| 8 | 局内积分商店 | 学会本轮资源 |
| 9 | 铜钱升级 | 学会永久成长 |
| 10 | 20 关目标 | 理解完整主线 |

## 15. MVP 建议范围

建议第一版只做一个可验证闭环。

必须做：

- 堆叠牌山点击。
- 只看上层遮挡的可点击规则。
- 主槽 7 格。
- 手动 `吃 / 碰 / 杠`。
- 组合候选展示。
- 满槽但有组合时不失败。
- 失败前救场基础流程。
- 洗牌、撤回、透视 3 个道具。
- 余牌简版和展开点数。
- 局内积分、铜钱、体力基础口径。
- 10 个 MVP 关卡，验证后扩到 20 关。
- 10 个局内奖励。
- 3 个局外升级：主槽容量、备用槽、满槽护符。

建议后置：

- 每日牌局。
- 在线排行榜。
- 复杂成就奖励。
- 弃牌符常驻道具。
- 完整胡牌和复杂番型。
- 高阶手动选牌挑战。
- 传说能力和大量事件。
- 深度商业化体力/付费。

## 16. 团队评审重点

请团队重点评审以下问题：

1. `吃 / 碰 / 杠` 手动发动是否足够好理解，是否需要更强的新手提示。
2. 组合候选区应该贴近槽位上方，还是点击按钮后展开。
3. 局内积分商店是关间出现，还是危局中也允许购买救场资源。
4. `弃牌符` 是否进入 MVP。
5. `胡牌目标` 是否进入第一版，还是只保留为第 20 关 Boss 概念。
6. 体力系统是否第一版上线，还是先隐藏。
7. 余牌详细点数是否从第一关开放。
8. 第一版原型选 GDevelop，还是直接 Cocos。
9. 主线 10 关验证后再扩 20 关，团队是否接受。
10. 程序化随机生成是否第一版就做，还是主线先用固定 seed。

## 17. 后续开发计划讨论入口

团队认可玩法后，再进入开发计划拆分。建议拆分顺序：

1. MVP 范围冻结。
2. 规则模型和测试。
3. 牌局配置和生成器。
4. 原型或 Cocos 工程选择。
5. UI 交互稿。
6. 数值表和 1-20 关节奏表。
7. Web 试玩和小程序发布计划。
