# 麻将 Roguelike 消除玩法规划

**日期**：2026-05-22  
**任务**：T030-T040  
**状态**：讨论稿 v0.2

## 1. 核心结论

本游戏不采用自动消除。玩家需要先把牌选入槽位，再自己判断并点击 `吃 / 碰 / 杠` 三个按钮来发动组合。

这个决定很关键：

- 它让游戏从“看系统自动合成”变成“玩家主动打麻将手牌”。
- 它能制造误判、犹豫、压槽位和策略选择。
- 它让 UI 里的 `吃 / 碰 / 杠` 按钮成为麻将氛围核心，而不是普通三消反馈。

推荐玩法结构：

```text
堆叠牌面选牌 -> 进入槽位 -> 玩家观察槽位 -> 吃/碰/杠按钮亮起 -> 玩家点击发动 -> 消除并结算奖励 -> 清空牌面或完成目标过关
```

## 2. 手动组合交互

### 2.1 基础流程

1. 玩家点击牌面上未被上层牌覆盖的牌。
2. 牌进入底部槽位。
3. 入槽动画播放期间，牌面、槽位和道具输入全部锁定。
4. 动画结束后，系统检测当前槽位里是否存在可发动组合。
5. 若存在组合，对应按钮从不可用状态切换为可用状态。
6. 按钮上方或槽位上方展示可发动组合候选。
7. 玩家选择候选组合，或手动选择 3-4 张槽内牌。
8. 只有当前选择满足 `吃 / 碰 / 杠` 条件时，对应按钮才可点击。
9. 玩家点击按钮后立即发动，不再弹二次确认。
10. 播放发动动画，移除对应牌。
11. 触发分数、局内积分、奖励、道具、关卡目标等结算。

系统不自动移除牌。

玩家把牌点入槽位后，不能手动撤销这次入槽。只有使用 `撤回` 道具，才能把最近进入槽位的一张牌放回原位置。

可点击牌的第一版规则只看遮挡关系：

```text
只要没有被上层牌覆盖，就可点击。
```

暂不加入传统“左右至少一侧打开”的麻将接龙规则，避免第一版理解成本过高。

### 2.2 按钮状态

三个按钮固定显示在槽位上方或右下侧，建议顺序：

```text
吃  碰  杠
```

状态分为 4 种：

| 状态 | 视觉 | 行为 |
| --- | --- | --- |
| 不可用 | 灰色文字、低透明、无边框或暗边框 | 点击无效，可轻微抖动提示“还差牌” |
| 可用 | 金红色文字、字上冒火、按钮边缘发光 | 点击发动对应组合 |
| 多选可用 | 金红色更强、按钮旁显示组合数量 | 点击后进入组合选择或自动选最优 |
| 冷却/禁用 | 暗红灰、火焰熄灭 | 特殊关卡或负面效果下不可发动 |

视觉建议：

- 默认灰色字：像麻将桌上未点燃的牌令。
- 可用状态：金红色火焰从字顶冒出，有“碰！”“杠！”的爽感。
- 发动时：按钮文字放大 110%，火焰拉出一笔书法拖尾。
- 不要用现代科技霓虹，保持麻将和国风味。

### 2.3 组合检测

槽位里允许系统检测，但发动由玩家决定。

`碰`：

- 3 张同花色同点数。
- 例如 `5万 5万 5万`。

`吃`：

- 同花色连续 3 张。
- 例如 `2条 3条 4条`。
- 第一版只允许顺子长度 3，不做更长顺子。

`杠`：

- 4 张同花色同点数。
- 例如 `8筒 8筒 8筒 8筒`。
- 杠的收益应明显高于碰，但更占槽位。

### 2.4 多组合冲突

同一槽位可能同时存在多个组合。

- 只要出现合法组合，对应 `吃 / 碰 / 杠` 按钮就进入可用状态。
- 可用按钮必须提示候选组合数量和将要消除的内容。
- 若只有一个组合，系统默认选中该组合，玩家点击按钮后直接发动。
- 若同类组合有多个，组合候选区列出每一组，玩家自由选择具体哪一组。
- 若 `吃 / 碰 / 杠` 同时可用，三个按钮都点亮，玩家决定先发动哪一种。
- 玩家选错组合后没有确认步骤；点击发动按钮即执行，这也是操作判断的一部分。

推荐优先级只用于默认高亮，不自动消除：

```text
杠 > 碰 > 吃
```

组合候选区建议贴近三个按钮或槽位上缘显示，不要做成远离牌面的弹窗。每个候选只展示必要信息，例如：

```text
吃：3万 4万 5万
碰：5万 5万 5万
杠：8筒 8筒 8筒 8筒
```

候选被选中时，槽内对应牌描边；未选中的合法候选保持弱高亮。

### 2.5 手动选牌挑战

基础模式中，玩家主要点击 `吃 / 碰 / 杠` 按钮，由系统列出可用组合。

后续高阶挑战可以加入“手动选牌出牌”：

1. 玩家先在槽位中手动选择 3-4 张牌。
2. 系统判断所选牌是否构成 `吃 / 碰 / 杠`。
3. 合法时对应按钮点燃。
4. 玩家点击按钮发动。
5. 不合法时按钮不亮，所选只是“槽内选择态”，不代表撤回入槽。

这个模式适合：

- 高阶周目。
- Boss 试炼。
- 成就挑战。
- 每日牌局高分规则。

它不建议放进新手前几关，因为会增加操作成本。

### 2.6 杠、碰、吃的冲突处理

允许冲突存在。

例如槽位里有：

```text
5万 5万 5万 5万
```

此时 `碰` 和 `杠` 都可以亮。

- 点 `碰`：消 3 张，留下 1 张，低风险，清槽快。
- 点 `杠`：消 4 张，高收益，但需要多占 1 个槽位。

再例如：

```text
3万 4万 5万 5万 5万
```

此时：

- `吃` 可以消 `3万 4万 5万`。
- `碰` 可以消 `5万 5万 5万`。

玩家选择其中一种后，另一种可能被破坏。这不是 bug，而是策略来源。

原则：

```text
系统提示所有合法动作，不替玩家做最优选择。
```

### 2.7 满槽时的操作锁定

主槽满时，先检测是否存在可发动组合。

- 如果存在合法 `吃 / 碰 / 杠`，玩家不能继续点击牌面入槽，必须先处理槽内组合。
- 如果存在多个组合，玩家仍然自由选择消除哪一组。
- 如果没有合法组合，进入失败前救场流程，见 `12.2 失败前救场顺序`。

这个规则保证玩家不会在有解的满槽状态下被系统提前判负，也避免满槽后继续点牌导致状态混乱。

## 3. 槽位系统

槽位不是单纯容量，而是游戏的核心成长属性。

### 3.1 默认槽位

MVP 默认：

- 初始槽位：`7`
- 最低槽位：`6`
- 局外永久最高：`9`
- 局内奖励临时最高：`10 或 11`
- 永久备用槽最高：`2`

原因：

- 7 格有羊了个羊用户认知。
- 手动组合比自动消除更占脑力，过低会挫败。
- 可成长槽位能形成长期目标。

### 3.2 槽位属性

建议把槽位拆成 5 个可成长属性：

| 属性 | 效果 | 价值 |
| --- | --- | --- |
| 槽位容量 | 增加底部槽位数量 | 最直接降低难度 |
| 备用槽 | 每关可临时收纳 1-2 张牌，不计入失败 | 降低卡死风险 |
| 槽位锁定 | 可锁住一张牌，防止撤回/洗牌影响 | 提供策略感 |
| 槽位净化 | 每关第一次满槽时自动清除一张低价值牌 | 新手保护 |
| 起手提示 | 开局高亮一个潜在组合方向 | 降低学习成本 |

MVP 先做：

- 槽位容量。
- 备用槽。
- 槽位净化。

`槽位锁定` 和 `起手提示` 可以后置。

### 3.3 局外升级

玩家通过货币升级槽位属性。升级是永久生效或赛季内生效。

第一版建议先永久生效，降低解释成本。

示例：

| 升级项 | 等级 | 效果 |
| --- | --- | --- |
| 槽位容量 | Lv.1 | 初始 7 格 |
| 槽位容量 | Lv.2 | 初始 8 格 |
| 槽位容量 | Lv.3 | 初始 9 格 |
| 备用槽 | Lv.1 | 每关 1 个备用格 |
| 备用槽 | Lv.2 | 每关 2 个备用格 |
| 槽位净化 | Lv.1 | 每局 1 次满槽自动移除 1 张 |
| 槽位净化 | Lv.2 | 每 5 关刷新 1 次 |

控制点：

- 槽位成长不能太快，否则关卡难度崩掉。
- 初期升级应明显有感，后期升级需要更多货币。
- 如果未来要商业化，槽位成长比直接卖道具更温和。

## 4. 经济和体力系统

收益分两层：`局内积分` 和 `铜钱`。

这两个东西不能混用，否则玩家会分不清当前这一局的资源和永久成长资源。

### 4.1 局内积分

局内积分只在当前一轮牌局内生效，失败或结束后清空。

获得方式：

| 来源 | 说明 |
| --- | --- |
| `吃` | 基础分最低，强调灵活清槽 |
| `碰` | 基础分中等，强调稳定刻子 |
| `杠` | 基础分最高，强调高风险高收益 |
| 连续同花色 | 给额外倍率或积分 |
| 关卡目标 | 完成指定目标给额外局内积分 |
| 局内奖励 | 部分奖励提高特定组合积分 |

MVP 占位数值：

| 组合 | 局内积分 |
| --- | --- |
| `吃` | +10 |
| `碰` | +20 |
| `杠` | +50 |
| 清一色连段 | 每段额外 +10% |
| 简化胡牌目标 | +80 |

消耗方式：

| 消耗 | 说明 |
| --- | --- |
| 买洗牌 | 本轮商店或关间购买 1 次洗牌 |
| 买撤回 | 购买 1 次撤回 |
| 买透视 | 购买 1 次透视 |
| 买弃牌符 | 后续可开放，强救场资源 |
| 刷新局内奖励 | 后续可开放，帮助 build 成型 |

局内积分不直接带出局外。后续可以设计“通关时按一定比例折算少量铜钱”，但 MVP 先不做，避免刷分变成刷铜钱。

### 4.2 铜钱

铜钱是局外长期资源，用于永久升级和养成。

获得方式：

| 来源 | 说明 |
| --- | --- |
| 过关奖励 | 每关或每个阶段结算铜钱 |
| 20 关通关 | 给大量首通铜钱 |
| 无尽层数 | 按最高层或本次到达层数结算铜钱 |
| 成就奖励 | 达成特殊打法或里程碑给铜钱 |
| 每日牌局 | 每日首胜或最佳成绩奖励 |
| 排行奖励 | 后续接排行榜后再开放 |

MVP 建议：

- 过关：+10 铜钱。
- 完成关卡目标：+10 铜钱。
- 20 关首通：额外 +300 铜钱。
- 无尽每 5 层：结算一次阶梯铜钱。

铜钱用途：

- 升级主槽容量、备用槽、满槽护符等基础成长。
- 解锁或升级初始道具次数。
- 解锁能力卡槽相关系统。
- 解锁图鉴、皮肤、按钮火焰特效等非数值奖励。
- 购买体力。

铜钱不建议在局内频繁购买救场道具。局内购买优先用局内积分，这样失败时不会让玩家感觉永久资源被瞬间吞掉。

### 4.3 永久升级消耗

优先消耗在槽位成长，不要一开始做太多商店项。

推荐升级成本：

| 项目 | Lv.2 | Lv.3 |
| --- | --- | --- |
| 主槽容量 | 120 | 360 |
| 备用槽 | 80 | 240 |
| 满槽护符 | 160 | 480 |

这些只是占位数值，后续需要跑关卡验证。

### 4.4 体力系统

每次开始一轮正式牌局消耗体力。

规则：

| 项目 | 建议值 |
| --- | --- |
| 单局消耗 | 5 点体力 |
| 体力上限 | 100 点 |
| 自然恢复 | 按时间恢复，具体间隔后续数值验证 |
| 铜钱购买 | 允许用铜钱购买少量体力 |
| 付费购买 | 后续商业化时可开放 |

体力只限制正式收益局，不建议限制新手引导、规则练习和低成本试玩。

### 4.5 失败保留口径

失败后当前轮次的局内能力和局内积分清空。

铜钱是否发放按模式区分：

| 模式 | 失败铜钱 |
| --- | --- |
| 普通 20 关闯关 | 建议只保留已过关结算铜钱 |
| 无尽牌山 | 按到达层数结算铜钱 |
| 每日牌局 | 可以给少量参与铜钱，但不超过通关收益 |
| 高阶周目 | 失败奖励更少，强调挑战 |

不允许失败后复活继续同一局。可以有失败前救场，但没有复活按钮。

## 5. 奖励系统重构

需要区分三类东西：

- 局内 Roguelike 奖励：本局 run 内生效，过关 3 选 1。
- 局外成长：用铜钱永久升级，主要围绕槽位。
- 道具：可主动点击使用，一般次数有限。

不要把三者混在一起，否则用户会不知道自己获得的是永久强化还是临时效果。

### 5.1 局内奖励定位

局内奖励应该改变打法，不只是降低难度。

分类：

| 类型 | 作用 |
| --- | --- |
| 组合强化 | 强化吃碰杠收益 |
| 花色构筑 | 鼓励围绕万/条/筒打 build |
| 槽位临时变化 | 本局临时改变槽位压力 |
| 风险收益 | 提高难度但提高收益 |
| 道具联动 | 改变洗牌、撤回、透视效果 |

### 5.2 MVP 10 个局内奖励

| 奖励 | 效果 | 设计目的 |
| --- | --- | --- |
| 红中火令 | `碰` 发动后，下次 `碰` 额外 +10 局内积分 | 鼓励碰刻子 |
| 顺水推舟 | `吃` 发动后，随机高亮一个可接近顺子的牌 | 教用户做顺子 |
| 明杠有赏 | `杠` 发动后，随机移除牌面 1 张未遮挡牌 | 让杠有爆发感 |
| 万字当头 | 万子组合分数 +50% | 花色 build |
| 条条生风 | 条子组合后，下一次选牌可撤回免费 | 花色 build |
| 筒心聚宝 | 筒子组合额外 +10 局内积分 | 花色 build |
| 留一手 | 本局槽位上限 +1 | 直接缓解压力 |
| 破釜沉舟 | 槽位少 1，但所有局内积分收益 +50% | 风险收益 |
| 余火未尽 | 发动任意组合后，随机点燃一个可用按钮 1 秒提示 | 反馈增强 |
| 老雀识路 | 每关开始自动提示一个可用组合方向 | 新手友好 |

### 5.3 暂缓奖励

这些后续再做：

- 复制牌。
- 改变牌面花色。
- 直接消除整层。
- 重新生成牌堆。
- 长链番型。

原因：这些容易破坏关卡可控性。

## 6. 道具体系重构

道具是主动按钮，和 `吃 / 碰 / 杠` 不同。

建议 UI 区分：

- `吃 / 碰 / 杠`：组合发动按钮，麻将核心。
- 道具：右侧竖排小按钮。

### 6.1 MVP 三个道具

| 道具 | 效果 | 使用限制 |
| --- | --- | --- |
| 洗牌 | 重排牌面中未进入槽位且未被遮挡关系锁死的牌 | 每局 1 次 |
| 撤回 | 将最近进入槽位的一张牌放回原位置 | 每局 2 次 |
| 透视 | 显示一层被遮挡牌 3 秒 | 每局 1 次 |

道具初始次数来自永久成长、局内奖励或关卡默认配置。局中额外购买时，优先消耗 `局内积分`。

`撤回` 是唯一的基础撤销方式。玩家点牌入槽后不能直接点一下取消，避免把槽位压力变成随便试错。

### 6.2 为什么不先做更多道具

第一版用户需要先学习：

- 选牌。
- 看槽位。
- 判断吃碰杠。
- 点击按钮发动。
- 理解奖励。
- 理解槽位成长。

道具过多会抢走核心玩法注意力。

### 6.3 道具升级方向

后续可以让局外成长影响道具：

| 升级项 | 效果 |
| --- | --- |
| 洗牌精通 | 洗牌后至少生成 1 个潜在组合 |
| 撤回精通 | 撤回不消耗次数的概率 +10% |
| 透视精通 | 透视时间从 3 秒变 5 秒 |

MVP 不建议先做。

## 7. 关卡目标

关卡目标比“胡牌算法”更适合第一版。

### 7.1 目标类型

| 目标 | 示例 |
| --- | --- |
| 清空目标 | 清空所有牌 |
| 组合目标 | 发动 2 次 `碰` |
| 花色目标 | 发动 3 次万子组合 |
| 特殊目标 | 最后一次必须用 `杠` |
| 胡牌目标 | 完成指定简化组合包 |

### 7.2 胡牌目标的轻量定义

第一版不做真实麻将胡牌。`胡牌目标` 定义为关卡要求的组合清单：

```json
{
  "type": "combo_package",
  "required": [
    { "combo": "chi", "suit": "wan", "ranks": [1, 2, 3] },
    { "combo": "peng", "suit": "tong", "rank": 5 }
  ]
}
```

用户看到的是：

```text
本关胡牌：一二三万 + 三个五筒
```

这样有麻将味，但实现和理解都简单。

## 8. 牌堆生成和孤张处理

每次牌局都应该随机，但不是完全随机。正确方式是受控随机：

```text
生成可消除组合包 -> 拆散成牌 -> 按层级放入牌山 -> 校验至少存在一条可解路径 -> 进入关卡
```

### 8.1 不按完整麻将牌组生成

本游戏不是传统麻将，不要求使用完整 136 张麻将，也不要求每张牌只有固定 4 张。

允许：

- 同一花色重复出现。
- 同一点数超过传统麻将 4 张。
- 初始简单关只使用一种花色。
- 教学关只使用少量点数。
- 高阶关再加入更多花色和复杂分布。

原因：

- 关卡需要服务消除和构筑，而不是模拟真实麻将牌桌。
- 低关用一种花色能让玩家先理解 `吃`。
- 重复牌能稳定制造 `碰 / 杠` 机会。

### 8.2 组合包生成

关卡生成不直接随机总牌数，而是先随机组合包。

组合包类型：

| 类型 | 内容 | 用途 |
| --- | --- | --- |
| 吃包 | 同花色连续 3 张 | 顺子基础 |
| 碰包 | 同花色同点数 3 张 | 刻子基础 |
| 杠包 | 同花色同点数 4 张 | 高收益冲突 |
| 目标包 | 关卡目标需要的指定组合 | 保证目标可完成 |
| 干扰包 | 暂时难以组牌的孤张或半成组合 | 制造槽位压力 |

总牌数公式：

```text
总牌数 = 3 * 吃/碰/目标三张组合数 + 4 * 杠组合数 + 干扰牌数
```

干扰牌不能完全无解，必须能通过奖励、道具、补牌、孤张处理或后续组合消化。

### 8.3 可解性要求

关卡只需要保证初始状态至少存在一条可解路径。

不保证玩家任意操作都能过。

允许玩家因为提前 `碰` 掉杠牌、拆掉顺子或误拿孤张而把局面打死。这是策略代价。

### 8.4 杠被碰后的孤张问题

如果某个杠包是：

```text
8筒 8筒 8筒 8筒
```

玩家提前发动 `碰`，会留下 1 张 `8筒`。

这张牌可能变成暂时无用牌。需要提供消化方式，否则玩家会感觉系统制造死牌。

可用机制：

| 机制 | 效果 | 适用 |
| --- | --- | --- |
| 后续补牌 | 牌山后续仍可能出现同点数牌，让孤张重新成碰 | 基础规则 |
| 备用槽 | 孤张可以先放备用槽，不占主槽失败压力 | 局外成长 |
| 弃牌符 | 消耗道具或奖励，移除 1 张槽位孤张 | 道具/奖励 |
| 换牌 | 将 1 张孤张变成同花色相邻点数或同点数牌 | 高阶奖励 |
| 杠后补牌 | 发动 `杠` 后从牌山抽取/揭示 1 张补牌 | 杠流奖励 |
| 孤张结算豁免 | 清空牌山且只剩少量孤张时，满足目标可过关 | 特定关卡 |

推荐基础版本：

- 不直接给免费弃牌。
- 先靠后续补牌、备用槽和道具解决。
- 部分 Roguelike 奖励再提供孤张消化。

### 8.5 孤张内部判定

孤张可以作为系统内部规则存在，但不直接在牌面上给玩家贴 `孤张` 或 `死孤张` 标签。

内部定义：

| 类型 | 判定 |
| --- | --- |
| 暂时孤张 | 当前槽内无法参与任何 `吃 / 碰 / 杠` 的牌 |
| 死孤张 | 结合记牌器后，未来也没有补牌机会的暂时孤张 |

死孤张不允许无限堆积，必须通过以下机制处理：

- 备用槽。
- 换牌。
- 弃牌符。
- 满槽护符。
- 特定关卡豁免。
- 局内能力提供的孤张消化。

玩家侧不直接看到“死孤张”标签，但可以通过 `余牌/牌谱记牌器`、组合候选和道具提示推断风险。这样能保留策略判断，不把系统答案完全喂给玩家。

## 9. 牌谱记牌器

页面上方需要显示本局牌具剩余的花色和数量。该系统叫 `牌谱记牌器`，用户侧可以叫 `余牌`。

它的核心价值：

- 让玩家判断后续还有没有补牌机会。
- 让玩家决定现在 `碰`，还是等第 4 张做 `杠`。
- 让玩家判断孤张是否还有机会通过 `吃 / 碰` 消化。
- 减少堆叠牌山带来的纯盲猜感。

### 9.1 显示方式

顶部默认显示简版：

```text
余牌  万12  条9  筒15
```

点击展开后显示详细点数：

```text
万：1 2 3 4 5 6 7 8 9
    2 0 1 3 1 0 2 1 2
条：1 2 3 4 5 6 7 8 9
    1 3 0 2 1 1 0 2 1
筒：1 2 3 4 5 6 7 8 9
    0 2 2 1 3 0 1 1 2
```

颜色建议：

- 数量 0：灰色。
- 数量 1：淡黄。
- 数量 2+：正常。
- 可与槽位组成组合的点数：金红描边。
- 残杠牌相关点数：火焰小标。

### 9.2 统计范围

记牌器统计本局未被消除的牌，包括：

- 牌山里还没点出的牌。
- 可见但未拿的牌。
- 主槽里的牌。
- 备用槽里的牌。

当牌被 `吃 / 碰 / 杠` 消除后，数量实时减少。

### 9.3 和透视的区别

记牌器不是透视。

| 系统 | 告诉玩家什么 | 不告诉玩家什么 |
| --- | --- | --- |
| 记牌器 | 本局还剩哪些牌、数量是多少 | 这些牌在哪里 |
| 透视 | 下一层部分隐藏牌在哪里 | 全局还剩多少牌 |

组合价值：

```text
记牌器告诉我：还有 1 张 5万。
透视告诉我：那张 5万 压在右侧牌山下面。
所以我决定先拆右侧。
```

### 9.4 对孤张的作用

如果主槽里剩一张残杠牌：

```text
8筒
```

记牌器显示：

```text
8筒 剩余 0
7筒 剩余 1
9筒 剩余 1
```

玩家可以判断它还能通过 `7筒 8筒 9筒` 被 `吃` 消化。

如果 `7筒 / 8筒 / 9筒` 都剩余 0，系统内部会把这张牌判为死孤张，但界面不直接贴标签。玩家应通过余牌信息判断它需要备用槽、弃牌符、换牌或特定奖励处理。

### 9.5 高阶限制

高阶挑战可以限制记牌器：

| 词缀 | 效果 |
| --- | --- |
| 暗牌山 | 只显示花色总数，不显示点数 |
| 乱牌谱 | 每关开始隐藏部分点数数量 |
| 无谱局 | Boss 关禁用详细记牌器 |

这样既保留记牌器的策略价值，又能在高阶模式中重新制造信息压力。

## 10. 局内 Roguelike 能力池

局内能力是每过一关 3 选 1 的奖励，只在当前一轮牌局内生效，失败后清空。

设计目标：

- 让每一轮有不同打法。
- 解决孤张、残杠牌、补牌和换牌问题。
- 让 `吃 / 碰 / 杠 / 花色 / 槽位 / 道具 / 信息` 都能形成构筑。
- 保持关卡可控，避免无限生成牌或随意移除牌。

### 10.1 强度边界

局内能力按效果强度分 4 档：

| 档位 | 允许效果 | 说明 |
| --- | --- | --- |
| 提示类 | 高亮、标记、显示趋势 | 最安全，可常见 |
| 收益类 | 加局内积分、加分、奖励品质提高 | 不改变牌局结构 |
| 调度类 | 撤回、备用槽、移动牌、延迟失败 | 改变压力但不改牌池 |
| 改牌类 | 移除牌、补牌、换牌、生成牌 | 最强，需稀有或有代价 |

原则：

- 直接移除牌不能过多。
- 直接生成牌必须受限制，优先生成“可见补牌”或“标记补牌”，不要无脑塞进槽位。
- 换牌应优先同花色相邻或同点数转换，不直接指定万能牌。
- 孤张处理能力可以强一点，因为它解决策略冲突的后果。

### 10.2 孤张 / 补牌 / 换牌流

这是当前最重要的能力方向，负责兜住残杠牌和误拆组合后的策略代价。

| 能力 | 稀有度 | 效果 | 类型 |
| --- | --- | --- | --- |
| 弃孤留成 | 普通 | 每关可移除 1 张主槽孤张 | 移除牌 |
| 废牌回炉 | 普通 | 移除孤张时获得局内积分 | 收益 |
| 补缺一张 | 普通 | 槽位中有两张接近组合时，高亮牌山中的缺口牌 | 提示 |
| 孤张有路 | 稀有 | 每关第一次孤张可变成同花色相邻点数 | 换牌 |
| 残杠寻牌 | 稀有 | 出现残杠牌时，标记牌山中最接近补成组合的牌 | 提示 |
| 回炉重铸 | 稀有 | 将 1 张孤张随机变成当前优势花色牌 | 换牌 |
| 断张不死 | 稀有 | 满槽失败时，先移除 1 张孤张再判定 | 延迟失败 |
| 孤注一掷 | 传说 | 清除主槽所有孤张，但本关主槽 -1 | 移除牌 / 代价 |

### 10.3 杠流

杠流高风险高收益，核心是“憋第四张”的判断和残杠牌处理。

| 能力 | 稀有度 | 效果 | 类型 |
| --- | --- | --- | --- |
| 明杠有赏 | 普通 | 发动 `杠` 后额外获得局内积分 | 收益 |
| 留杠不碰 | 普通 | 槽位已有 3 张相同牌时，记牌器标出是否还有第 4 张 | 信息 |
| 杠后补牌 | 稀有 | 发动 `杠` 后揭示一张可形成新组合的牌 | 补牌 |
| 残杠有赏 | 稀有 | 每消化 1 张残杠牌，获得局内积分和分数 | 收益 |
| 四方来财 | 稀有 | `杠` 局内积分收益翻倍，但本关主槽 -1 | 风险收益 |
| 杠上开花 | 传说 | 发动 `杠` 后获得 1 个临时局内奖励，持续 1 关 | 奖励 |
| 补杠成局 | 传说 | 残杠牌可与任意同点数牌组成特殊 `补杠` 消除 | 改规则 |

### 10.4 吃流

吃流强调顺子、灵活和路线规划。

| 能力 | 稀有度 | 效果 | 类型 |
| --- | --- | --- | --- |
| 顺水推舟 | 普通 | 发动 `吃` 后，高亮一个可接近顺子的牌 | 提示 |

| 小顺补位 | 稀有 | `吃` 后有概率揭示同花色相邻牌 | 补牌 |
| 步步相连 | 稀有 | 每关第一次 `吃` 后返还 1 次撤回 | 道具联动 |
| 顺子成风 | 传说 | 每连续 `吃` 一次，顺子收益递增，断连后重置 | 构筑 |

### 10.5 碰流

碰流强调稳定清槽和防守。

| 能力 | 稀有度 | 效果 | 类型 |

### 10.6 花色流

花色流围绕 `万 / 条 / 筒` 做构筑。

### 10.10 能力池初始规模

当前规划共 44 个局内能力：

- 孤张 / 补牌 / 换牌流：8 个。
- 杠流：7 个。
- 吃流：5 个。
- 碰流：5 个。
- 花色流：6 个。
- 槽位流：6 个。
- 道具流：6 个。
- 信息流：5 个。

后续实现时可以先取每类 2-3 个做可玩闭环，再逐步扩充。

### 10.11 稀有度和出现规则

建议：

- 普通：前 5 关即可出现。
- 稀有：第 4 关后出现。
- 传说：Boss 关、事件、无尽高层或高阶周目出现。

限制：

- 同一轮中，直接移除牌能力最多同时出现 2 个。
- 直接补牌/换牌能力需要稀有以上。
- 传说能力不能连续关卡高频出现。
- 能力选择需要根据玩家已有构筑做加权，但不能完全锁死。

### 10.12 和记牌器联动

记牌器参与以下能力：

- `留杠不碰`：判断第 4 张是否仍存在。
- `牌谱清明`：高亮可补组合点数。
- `看张听路`：判断孤张还能通过哪些牌消化。
- `余牌推演`：预览消除后余牌变化。

记牌器被高阶词缀限制时，这些能力可以失效或降级。

## 11. 永久固化能力和能力卡槽

这里需要把两个容易混淆的东西拆开：

- `手牌槽位`：底部放牌空间，决定每关的容错和压迫感。
- `能力卡槽`：开局前装备永久能力的位置，决定玩家这轮偏向什么打法。

所以高阶挑战里说的 `卡槽压缩`，压缩的是 `能力卡槽`，不是直接把底部手牌槽位都砍掉。手牌槽位也可以被关卡词缀临时影响，但它属于另一条难度线。

`透视` 也不等于扩槽。透视的价值是看到隐藏牌的位置，帮助规划下一步拆哪片牌山；它不增加放牌空间，也不直接救满槽。

### 11.1 永久能力分层

永久能力分成 4 层：

| 层级 | 是否占能力槽 | 生效方式 | 作用 |
| --- | --- | --- | --- |
| 基础成长 | 否 | 自动生效 | 降低基础压力，提供长期成长 |
| 固化能力 | 是 | 开局前装备 | 决定长期 build 方向 |
| 起局能力 | 是 | 每轮开局触发 | 调整起手和首轮节奏 |
| 道具强化 | 是 | 强化主动道具 | 提升洗牌、撤回、透视、备用槽等工具价值 |

这样拆的好处是：

- 玩家不用在所有永久能力里纠结，基础成长买了就生效。
- 固化能力负责“我这局想玩什么流派”。
- 起局能力负责开局手感。
- 道具强化负责工具偏好，不抢吃碰杠核心位置。

### 11.2 基础成长

基础成长用铜钱升级，永久自动生效，不占能力卡槽。

| 能力 | 效果 | 说明 |
| --- | --- | --- |
| 扩建手牌架 I | 主槽 7 -> 8 | 第一阶段最有感成长 |
| 扩建手牌架 II | 主槽 8 -> 9 | 推荐永久上限 |
| 备用牌位 I | 解锁 1 个备用槽 | 用来临时放孤张 |
| 备用牌位 II | 备用槽 +1 | 备用槽永久最高 2 |
| 满槽护符 I | 每轮第一次满槽且无组合时，移除 1 张孤张 | 新手保护 |
| 满槽护符 II | 满槽保护每 5 关刷新 1 次 | 中期保护 |
| 铜钱袋 I | 过关铜钱 +10% | 加快早期成长 |
| 积分牌袋 | 组合局内积分 +10% | 鼓励主动做组合 |
| 初始洗牌 | 开局洗牌 +1 | 救场资源 |
| 初始撤回 | 开局撤回 +1 | 纠错资源 |
| 初始透视 | 开局透视 +1 | 规划资源 |
| 每日俸钱 | 每日首局额外铜钱 | 回访奖励 |

手牌槽位建议保持：

| 类型 | 数量 |
| --- | --- |
| 初始主槽 | 7 |
| 永久主槽上限 | 9 |
| 局内临时主槽上限 | 10 或 11 |
| 永久备用槽上限 | 2 |

不建议永久升到 10。10 格会显著降低底部槽位压力，后期更适合作为局内奖励或特殊事件的短期状态。

### 11.3 固化能力

固化能力占用 `固化能力槽`，默认东风场可装备 3 个。

| 能力 | 类型 | 效果 |
| --- | --- | --- |
| 顺势而吃 | 吃流 | `吃` 后更容易发现下一组顺子方向 |
| 小顺直觉 | 吃流 | 记牌器高亮小顺子缺口 |
| 稳手成碰 | 碰流 | `碰` 的局内积分和分数更稳定 |
| 刻子直觉 | 碰流 | 同点数牌更容易被提示 |
| 蓄势开杠 | 杠流 | `杠` 的奖励提高，但更依赖等待第 4 张 |
| 杠牌预感 | 杠流 | 槽内已有 3 张相同牌时，提示第 4 张是否还在牌山中 |
| 万字偏好 | 花色流 | 万子组合收益提高 |
| 条子偏好 | 花色流 | 条子组合收益提高 |
| 筒子偏好 | 花色流 | 筒子组合收益提高 |
| 孤张老手 | 孤张流 | 每关第一次孤张更容易被消化 |
| 残杠不亏 | 孤张流 | 残杠牌被消化时获得额外局内积分 |
| 牌谱清明 | 信息流 | 记牌器中可补当前槽位组合的点数加亮 |
| 看张听路 | 信息流 | 选中孤张时提示还能通过哪些牌消化 |
| 稳健牌手 | 防守流 | 降低奖励上限，换取更高容错 |
| 窄槽高手 | 风险流 | 主槽越紧，过关收益越高 |
| 多多益善 | 资源流 | 更容易获得铜钱和道具类局内奖励 |
| 旧招翻新 | 变体流 | 每轮可强化 1 个已有局内奖励 |

装备限制建议：

- `万字偏好`、`条子偏好`、`筒子偏好` 同时只能装备 1 个。
- `吃 / 碰 / 杠` 三类核心偏好最多装备 2 个。
- `稳健牌手` 和 `窄槽高手` 不建议同时装备。
- 直接移除牌或补牌相关固化能力要少，避免永久能力直接碾压关卡。

### 11.4 起局能力

起局能力占用 `起局能力槽`，默认东风场 1 个。

| 能力 | 效果 | 说明 |
| --- | --- | --- |
| 开局择运 | 开局 3 选 1 奖励可刷新 1 次 | 更容易成型 |
| 先手积分 | 开局获得少量局内积分 | 偏局内商店 |
| 明牌起手 | 开局高亮一条可行组合路径 | 新手友好 |
| 稳手开局 | 第 1 关主槽 +1，但局内积分收益略降 | 稳妥 |
| 三选刷新 | 第一次局内奖励可额外刷新 | 构筑稳定 |
| 起手顺风 | 开局随机指定一个优势花色 | 支持花色流 |

### 11.5 道具强化

道具强化占用 `道具强化槽`，默认东风场 1 个。

| 能力 | 效果 | 说明 |
| --- | --- | --- |
| 洗牌精通 | 洗牌后更容易保留潜在组合 | 让洗牌从救场变成规划 |
| 撤回精通 | 撤回有概率返还次数 | 纠错能力 |
| 透视精通 | 透视时间更长，并能显示更深一层的轮廓 | 强化规划价值 |
| 备用精通 | 备用槽使用更灵活 | 适合孤张流 |
| 弃牌符袋 | 每轮获得少量弃牌符资源 | 强能力，建议后期开启 |
| 道具回气 | 每过数关恢复 1 个随机道具 | 中期续航 |

透视的具体用途：

- 看下一层隐藏牌在哪里。
- 判断记牌器里显示的关键牌大概压在哪片牌山下。
- 决定先拆左侧还是右侧。
- 帮助玩家等第 4 张做 `杠`，或者判断孤张是否有救。

透视不是无脑救命道具。它适合做规划，不适合替代洗牌、撤回和弃牌。

### 11.6 能力卡槽基线和高阶压缩

默认卡槽建议：

| 模式 | 固化能力槽 | 起局能力槽 | 道具强化槽 |
| --- | --- | --- | --- |
| 普通闯关 / 东风场 | 3 | 1 | 1 |

高阶周目压缩：

| 周目 | 固化能力槽 | 起局能力槽 | 道具强化槽 | 额外限制 |
| --- | --- | --- | --- | --- |
| 东风场 | 3 | 1 | 1 | 无 |
| 南风场 | 3 | 1 | 1 | 随机禁用 1 个基础成长 |
| 西风场 | 2 | 1 | 1 | 备用槽效果降低 |
| 北风场 | 2 | 0 | 1 | 起局能力禁用 |
| 雀圣场 | 1 | 0 | 0 | 部分道具强化禁用 |

这个设计的重点是：后期不是只增加牌山层数，而是要求玩家在更少的永久能力里做选择。

## 12. 失败和难度

失败条件：

- 槽位满。
- 没有可发动组合。
- 没有可用道具或备用槽救场。
- 没有可触发的护符或首败保护。

手动发动后，需要重新定义“满槽失败”：

- 如果槽位满但存在可发动组合，不立刻失败。
- 只要玩家还能点击 `吃 / 碰 / 杠`，游戏应等待玩家操作。
- 玩家发动后腾出槽位，继续游戏。
- 若槽位满且三个组合按钮都不可用，才失败。

这能避免玩家明明有碰却因为系统判定过早失败。

### 12.1 危局状态

当主槽满时，游戏进入 `危局检测`：

```text
主槽满 -> 锁定继续选牌 -> 检测可发动组合 -> 检测救场资源 -> 判定继续或失败
```

危局状态下：

- 不能继续点击牌面入槽。
- 如果有组合，只能先处理组合。
- 如果没有组合，但有救场资源，允许救场。
- 如果没有组合也没有救场资源，才正式失败。

### 12.2 失败前救场顺序

推荐触发顺序：

1. `组合检测`：如果有可发动 `吃 / 碰 / 杠`，不失败，锁定玩家先消除。
2. `备用槽自动救场`：如果备用槽有空位，系统自动把 1 张主槽牌移入备用槽。
3. `满槽护符`：如果装备或拥有护符，自动移除 1 张主槽中的内部死孤张；没有死孤张时，移除低价值孤张。
4. `救场道具窗口`：如果还有能改变现状的道具，暂停失败判定，让玩家选择是否使用。
5. `首败保护`：每轮第一次真正失败前，随机丢弃主槽中的 1 张牌。
6. `失败结算`：以上都无法改变现状时，本轮失败。

这个顺序的原则是：

- 先保留玩家主动组合选择。
- 再使用不直接删牌的备用槽。
- 再消耗被动护符。
- 再给玩家主动道具选择。
- 最后触发一次首败保护。

### 12.3 备用槽自动救场

备用槽可以自动救场。

当主槽满且无组合时，如果备用槽有空位，系统自动移动 1 张主槽牌到备用槽。移动优先级：

```text
内部死孤张 > 暂时孤张 > 当前最不接近组合的牌
```

备用槽里的牌默认不参与 `吃 / 碰 / 杠` 检测。玩家需要通过道具、奖励或关卡规则把备用槽牌移回主槽，或在结算时处理。

### 12.4 满槽护符触发

满槽护符是被动救场，不需要玩家点击。

触发条件：

- 主槽已满。
- 没有可发动组合。
- 备用槽无法自动救场。
- 护符次数仍可用。

触发效果：

- 优先移除内部死孤张。
- 没有死孤张时，移除暂时孤张。
- 仍没有孤张时，随机移除 1 张低价值牌。

护符不能无限刷新。基础成长可以提供每轮 1 次；更高等级可以每 5 关刷新 1 次。

### 12.5 救场道具窗口

失败瞬间可以使用道具，但只允许使用“能改变当前失败状态”的道具。

可改变现状的例子：

- `撤回`：把最近进入槽位的牌退回。
- `弃牌符`：移除 1 张槽内牌。
- `换牌`：把 1 张孤张变成可组合牌。
- 强化后的 `洗牌`：如果它能把备用槽或槽内孤张重新调度。

不能改变现状的例子：

- 普通 `透视` 只显示隐藏位置，不释放主槽，不能单独阻止失败。
- 普通 `洗牌` 只重排牌山，不改变已满主槽，不能单独阻止失败。

### 12.6 失败结算

不允许复活。

失败后：

- 本轮局内能力清空。
- 本轮局内积分清空。
- 未过关部分不发过关铜钱。
- 已经结算到局外账户的铜钱保留。
- 无尽牌山按到达层数结算铜钱、成就和本地记录。

## 13. MVP 推荐版本

`麻将 Roguelike 消除 v0.1`：

- 手动点击牌进入槽位。
- 只有未被上层牌覆盖的牌可点击。
- 入槽动画期间锁定输入。
- `吃 / 碰 / 杠` 三按钮常驻。
- 按钮默认灰色，满足条件后金红冒火。
- 组合候选展示在按钮或槽位上方，玩家自由选择。
- 玩家点击按钮后立即消除，不做二次确认。
- 初始 7 槽位。
- 槽位满但可发动组合时不失败。
- 3 个道具：洗牌、撤回、透视。
- 顶部 `余牌` 简版显示，展开可看点数数量。
- 2 层收益：局内积分用于本轮买道具，铜钱用于永久成长。
- 每局消耗 5 体力，体力上限 100。
- 3 个局外升级：槽位容量、备用槽、槽位净化。
- 失败前按 `组合 -> 备用槽 -> 满槽护符 -> 救场道具 -> 首败保护 -> 失败` 判定。
- 不允许复活。
- 10 个局内 Roguelike 奖励。
- 10 个 MVP 关卡先验证手感，再扩到 20 关。

## 14. 最终模式结构

最终结构采用 5 个模式/系统：

```text
闯关模式 -> 无尽牌山 -> 高阶周目
      \        \        \
       \        \        -> 成就图鉴
        -> 每日牌局
```

这套结构的目标是：

- 20 关提供明确首通目标。
- 无尽牌山提供长期挑战。
- 高阶周目提供深度难度。
- 每日牌局提供回访理由。
- 成就图鉴提供收集和打法目标。

### 14.1 闯关模式

闯关模式是玩家第一次完整理解游戏的主线。

结构：

- 固定 20 关。
- 第 1-5 关教学和爽感。
- 第 6-10 关开始引入关卡目标。
- 第 11-15 关开始要求构筑方向。
- 第 16-19 关给高压组合和花色目标。
- 第 20 关是 `胡牌 Boss 关`。

通关奖励：

- 大量铜钱。
- 首通徽章。
- 解锁无尽牌山。
- 解锁高阶周目 1。
- 解锁新的局内奖励池。

用户表达：

```text
打穿东风牌山，解锁无尽挑战。
```

### 14.2 无尽牌山

无尽牌山是 20 关后的核心长期挑战。

入口：

- 首次通关 20 关后解锁。

规则：

- 从第 21 层开始继续挑战。
- 每 5 层一个小 Boss。
- 每 10 层一个大 Boss。
- 层数越高，牌山越厚、遮挡越复杂、目标越苛刻。
- 失败后结算最高层数、铜钱和成就。

挑战增长方式：

| 层数 | 变化 |
| --- | --- |
| 21-30 | 牌山层数增加，目标更频繁 |
| 31-50 | 负面词缀加入，例如禁用一次洗牌 |
| 51-80 | 胡牌目标更复杂，隐藏牌更多 |
| 81+ | 组合目标、花色目标、风险词缀叠加 |

玩家追求：

- 本次能到第几层。
- 某个构筑能撑多远。
- 能否突破历史最高层。

### 14.3 高阶周目

高阶周目是通关后的难度轮回。

建议用麻将风向包装：

| 周目 | 名称 | 变化 |
| --- | --- | --- |
| 0 | 东风场 | 基础难度 |
| 1 | 南风场 | 牌山更厚，目标更多 |
| 2 | 西风场 | 负面词缀加入，道具限制增加 |
| 3 | 北风场 | 初始槽位压力更高，Boss 目标更复杂 |
| 4+ | 雀圣场 | 高压挑战，奖励品质更高 |

每通一次 20 关，解锁下一周目。

高阶周目不是简单加数值，而是加规则变化：

- 初始槽位 -1 或成长收益降低。
- 某些关卡禁用洗牌。
- 隐藏层更多。
- 胡牌目标更复杂。
- 铜钱收益提高。
- 高品质奖励出现率提高。

### 14.4 每日牌局

每日牌局提供轻量回访。

规则：

- 每天一个固定牌山种子。
- 所有人面对同一套关卡、奖励池和初始条件。
- 每天只记录一次最佳成绩。

成绩维度：

- 通关层数。
- 得分。
- 铜钱收益。
- 使用道具次数。
- 最大连续同花色组合。

第一版可以只做本地记录，后续再接排行榜。

### 14.5 成就图鉴

成就图鉴用于承接长期目标。

成就不只做次数累计，要绑定特殊打法：

| 成就 | 条件 |
| --- | --- |
| 初入牌山 | 首次通关第 5 关 |
| 东风破 | 首次通关 20 关 |
| 杠上开花 | 一轮内发动 10 次 `杠` |
| 清一色 | 连续 5 次使用同一花色组合 |
| 绝境翻盘 | 满槽状态下连续发动 3 次组合并过关 |
| 七槽大师 | 不升级槽位通关 20 关 |
| 百层牌山 | 无尽牌山达到第 100 层 |
| 不洗牌通关 | 不使用洗牌通关 20 关 |

成就奖励：

- 铜钱。
- 称号。
- 牌面皮肤。
- 按钮火焰特效。
- 牌山背景主题。

## 15. 最终长期循环

```text
打 20 关首通
-> 解锁无尽牌山
-> 冲更高层数
-> 赚铜钱
-> 升级槽位 / 道具 / 初始能力
-> 解锁更高周目
-> 尝试新流派
-> 完成成就和每日牌局
-> 回到无尽牌山冲纪录
```

这个循环里有三种成就感：

- 通关成就：我打穿了 20 关。
- 层数成就：我无尽牌山打到 50、100、200 层。
- 构筑成就：我用 `杠流`、`万字流`、`极限七槽流` 都打穿了。

## 16. 高阶挑战系统

高阶挑战不只靠增加牌数。最终采用：

```text
牌山层数增长 + 词缀系统 + 随机事件 + 卡槽压缩 + Boss 试炼
```

设计目标：

- 牌山层数负责基础压力。
- 词缀负责规则变化。
- 随机事件负责选择和惊喜。
- 卡槽压缩负责限制局外成长碾压。
- Boss 试炼负责阶段记忆点。

### 16.1 难度压力来源

| 压力 | 说明 | 示例 |
| --- | --- | --- |
| 牌山压力 | 堆叠更厚，遮挡更复杂 | 牌山层数 +1，目标牌更深 |
| 能力压力 | 限制永久能力或卡槽 | 禁扩槽、固化能力槽 -1 |
| 事件压力 | 关前出现选择或变化 | 下一关禁透视但奖励提高 |
| 目标压力 | 过关条件更严格 | 必须完成胡牌目标 |
| 资源压力 | 道具和铜钱变紧 | 洗牌次数 -1，铜钱收益下降 |

### 16.2 无尽层增长建议

| 层数 | 增长内容 |
| --- | --- |
| 21-30 | 牌山层数增加，目标更频繁 |
| 31-40 | 开始出现 1 个词缀 |
| 41-60 | 词缀 + 随机事件 |
| 61-80 | 部分永久能力被限制 |
| 81-100 | 词缀组合出现 |
| 100+ | 每 10 层一个 Boss 试炼 |

### 16.3 高阶周目卡槽压缩

| 周目 | 固化能力槽 | 起局能力槽 | 道具强化槽 | 额外限制 |
| --- | --- | --- | --- | --- |
| 东风场 | 3 | 1 | 1 | 无 |
| 南风场 | 3 | 1 | 1 | 随机禁用 1 个基础成长 |
| 西风场 | 2 | 1 | 1 | 备用槽效果降低 |
| 北风场 | 2 | 0 | 1 | 起局能力禁用 |
| 雀圣场 | 1 | 0 | 0 | 部分道具强化禁用 |

这个结构能让玩家重新思考配装，而不是后期靠永久成长碾压。

### 16.4 第一批高阶词缀

| 词缀 | 效果 | 类型 |
| --- | --- | --- |
| 厚牌山 | 本关牌山层数 +1 | 牌山压力 |

### 16.7 设计注意事项

- 负面事件尽量来自玩家选择，不要无预警强塞。
- 词缀需要在关卡开始前明确展示。
- 能力限制要说明具体禁用了什么，避免玩家感觉系统失效。
- Boss 试炼要有明显主题和奖励，不要只是普通关变难。
- 卡槽压缩适合高阶周目和无尽后段，不适合新手主线。这里的卡槽指 `能力卡槽`，不是底部 `手牌槽位`。

## 17. 新手引导

新手引导不是单独的“关卡类型”，而是覆盖前几局的引导层。关卡仍然是正常牌局，只是逐步开放信息和按钮。

建议顺序：

| 步骤 | 开放内容 | 目标 |
| --- | --- | --- |
| 1 | 点击未被覆盖的牌入槽 | 学会可点击规则 |
| 2 | `碰` 按钮点亮 | 学会手动发动，不自动消除 |
| 3 | `吃` 按钮点亮 | 学会同花色顺子 |
| 4 | `杠` 按钮点亮 | 学会四消和高收益 |
| 5 | 多组合候选 | 学会自由选择组合 |
| 6 | 余牌展开 | 学会判断补牌和孤张风险 |
| 7 | 槽满危局 | 学会先消除、再救场、最后失败 |
| 8 | 局内积分商店 | 学会用积分买洗牌、撤回、透视 |
| 9 | 铜钱升级 | 学会永久养成 |
| 10 | 20 关目标 | 学会 run 的完整目标 |

新手引导只解释玩家当下需要的规则，不提前讲完整能力池、周目、无尽和高阶词缀。

## 18. 待讨论问题

1. `吃 / 碰 / 杠` 按钮最终放在槽位上方，还是右侧道具上方？
2. 组合候选区是横向贴在槽位上方，还是点按钮后在按钮上方展开？
3. 局内积分商店是每关后出现，还是危局/关中也允许购买？
4. 失败保留铜钱的精确口径是否按“已过关即入账”执行？
5. 局内奖励是否每关都给，还是每 2 关给一次？
6. `胡牌目标` 是第 5 关后出现，还是先不进 MVP？
7. `弃牌符` 是否进入 MVP，还是只作为稀有局内奖励或后续道具？
8. 每日牌局是否需要固定种子公开，方便玩家讨论和复盘？
9. 高阶周目使用 `东南西北风` 命名，还是用更直白的 `一周目 / 二周目`？
10. 高阶词缀是否允许玩家在关前预览并选择路线？
11. 随机事件的负面结果是否必须都给补偿奖励？
12. 记牌器默认是否显示完整剩余数量，还是只在通关 20 关后解锁详细点数？
13. 牌堆生成约束需要单独展开：每关总牌数、组合包比例、干扰包上限、死孤张容忍数量和可解路径校验。
