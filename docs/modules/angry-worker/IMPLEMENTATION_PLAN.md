## 4. 关卡生成算法

### 4.1 输入输出

```javascript
// 输入
{
  levelNumber: 1,      // 关卡数，决定难度
  seed: 123456,        // 随机种子
  width: 750,          // 屏幕宽
  height: 1334         // 屏幕高
}

// 输出
{
  structures: [...],   // 建筑数组（砖块 / 木板 / 冰块 / 炸弹桶）
  targets: [...],      // 目标数组（猪的位置）
  specials: [...],     // 特殊元素（反弹板 / 黑洞等）
  shooter: {...},      // 弹射参数（起始位置）
  difficulty: {...},   // 难度参数（时间限制等）
  bossTemplate: null   // Boss 模板（每 5 关）
}
```

### 4.2 难度曲线

| 关卡 | 建筑数 | 目标数 | 特殊元素 | 时间限制 | Boss |
|------|--------|--------|----------|----------|------|
| 1-3 | 5-8 | 1 | 无 | 无 | 无 |
| 4-6 | 8-15 | 1-2 | 1 个 | 无 | 无 |
| 7-10 | 15-25 | 2 | 2 个 | 60 秒 | 第 5 关 |
| 11-15 | 25-40 | 2-3 | 3 个 | 45 秒 | 第 10 关 |
| 16-20 | 40-60 | 3 | 4 个 | 30 秒 | 第 15 关 |
| 20+ | 60-100 | 3-4 | 全部 | 20 秒 | 第 20 关+ |

### 4.3 核心算法流程

```javascript
function generateLevel(levelNumber, seed) {
  const rng = new SeededRandom(seed);
  const difficulty = calculateDifficulty(levelNumber);
  const structures = generateStructures(difficulty, rng);
  const targets = placeTargets(structures, difficulty, rng);
  const specials = addSpecialElements(difficulty, rng);
  const shooter = generateShooterParams(difficulty);
  return { structures, targets, specials, shooter, difficulty };
}
```

| 名称 | 效果 | 叠加 | Build 流派 |
|------|------|------|------------|
| 重拳出击 | 发射力度 +25% | 加法 | 暴力流 |

| 弹力大师 | 弹跳次数 +1 | 加法 | 弹跳流 |
| 穿透之眼 | 穿透 1 个砖块 | 加法 | 技巧流 |
| 分裂弹 | 碰撞后分裂为 2 个 | 不叠加 | 炸弹流 |
| 炸弹核心 | 碰撞后范围爆炸 50px | 范围叠加 | 炸弹流 |
| 额外弹药 | 发射次数 +1 | 加法 | 生存流 |
| 时间延长 | 时间限制 +10 秒 | 加法 | 生存流 |

| 连击狂热 | Combo 上限翻倍 | 不叠加 | 秀技流 |

- 暴力流：重拳 ×3 + 破坏 ×2 = 一发粉碎一切
- 炸弹流：分裂弹 + 炸弹核心 + 破坏之王 = 一撞清屏
- 弹跳流：弹力 ×3 + 穿透 = 全场乱弹不死
