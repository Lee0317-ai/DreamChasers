# 打工人弹射解压

> 一句话：一款面向打工人的 Roguelike 物理弹射解压游戏，每次进入都是全新体验，无限重玩。
>
> 核心公式：`解压（情绪价值） + Roguelike（机制价值） + 社交（传播价值） = 完整产品`

## 1. 产品定位

| 维度 | 说明 |
|------|------|
| **目标用户** | 20-35 岁职场人群，工作压力大，需要短时宣泄 |
| **核心场景** | 通勤、午休、加班间隙，5-15 分钟碎片化时间 |
| **平台** | 微信小程序（即点即玩，无需下载） |
| **差异化** | Roguelike 随机关卡生成 + 本地图片替换打击目标 + 职场吐槽系统 |
| **变现** | IAA（激励视频广告）：复活、Buff 刷新、双倍金币 |

## 2. 核心循环

```
开始游戏
  ↓
生成第 1 关（算法随机）
  ↓
选择武器（重拳 / 弹跳 / 炸弹）
  ↓
可选：换目标脸（本地图片替换）
  ↓
弹射 → 碰撞 → Combo 连击 → 击中吐槽
  ↓
通关 → 3 选 1 Buff → 生成下一关（难度 +1）
  ↓
...（每 5 关 1 个 Boss）...
  ↓
失败 → 结算分数 → 解锁成就 → 升级局外属性
  ↓
再来一局（全新关卡，全新体验）
```

## 3. 关键特性概览

### 3.1 核心玩法

| 功能 | 说明 |
|------|------|
| 拖拽拉弓弹射 | 愤怒小鸟式抛物线 + 重力，Matter.js 物理引擎 |
| 随机关卡生成 | 算法生成建筑 + 目标 + 特殊元素，无限关卡 |
| 难度递增系统 | 建筑密度 / 目标数 / 特殊元素 / 时间压力 |
| 种子系统 | 每日挑战固定种子，公平竞技 |

### 3.2 武器与 Buff

| 武器 | 特性 |
|------|------|
| 重拳球 | 质量大、破坏强、抛物线短直 |
| 弹跳球 | 弹性极高、可弹跳 5 次 |
| 炸弹球 | 碰撞后 2 秒爆炸、范围伤害 |

| Buff 类别 | 代表 Buff |
|-----------|-----------|
| 力量型 | 重拳出击（力度 +25%）、破坏之王（伤害 +30%） |
| 技巧型 | 弹力大师（弹跳 +1）、穿透之眼（穿透砖块） |
| 特效型 | 分裂弹、炸弹核心 |
| 生存型 | 额外弹药、时间延长 |
| 爽感型 | 慢镜头大师、连击狂热 |

### 3.3 爽点系统

| 功能 | 说明 |
|------|------|
| Combo 连击 | 连续击中递增伤害 + 视觉反馈，最高 20 连击慢镜头 |
| Boss 战 | 每 5 关 1 个 Boss（移动型 / 护盾型 / 召唤型 / 反击型） |
| 吐槽系统 | 30 条搞笑 + 阴阳怪气台词，角色专属，随机弹出 |
| 本地图片替换 | 用户上传图片替换目标头部，仅本地存储，分享图不带 |

### 3.4 留存系统

| 功能 | 说明 |
|------|------|
| 经典 Roguelike | 无限关卡，失败即结束，追求高分 |
| 每日挑战 | 固定种子，所有玩家同一关卡，排行榜 |
| 无尽发泄模式 | 无限制，建筑不断生成，纯解压 |
| Boss Rush | 连续挑战 Boss，解锁条件：经典模式第 20 关 |
| 局外成长 | 金币 + 5 个升级项（力度 / 弹力 / 弹药 / 金币 / 开局 Buff） |
| 7 日签到 | 每日奖励，第 7 天稀有角色 |
| 称号系统 | 实习生 → 打工皇帝，6 个等级 |

### 3.5 社交系统

| 功能 | 说明 |
|------|------|
| 分享图生成 | 通关后生成梗图，角色 + 吐槽 + 战绩 + 二维码 |
| 5 个排行榜 | 全服总分 / 今日 / 本周 / 好友 / 每日挑战 |

## 4. 技术栈

| 层级 | 技术 |
|------|------|
| 平台 | 微信小程序 |
| 物理引擎 | Matter.js（2D 刚体物理） |
| 渲染 | Canvas 2D |
| 存储 | `wx.setStorageSync`（本地图片、进度、设置） |
| 后端 | 微信云开发（免费额度足够排行榜、用户数据） |
| 音效 | freesound.org 免费素材 |
