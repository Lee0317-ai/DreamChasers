# 弹珠机福利玩法实施计划

## 1. 阶段定位

本计划仅作为后续候选实现依据，不代表当前立即进入开发。当前任务 T145 只完成文档落档。

## 2. 推荐阶段

### 阶段 1：无奖励物理原型

目标：验证弹射手感和落点乐趣。

范围：

- 拉杆或拖拽发射。
- 钉阵碰撞。
- 多个落点轨道。
- 亮灯轨道和倍率展示。
- 纯本地结算动画。

不接：

- 账号。
- 积分。
- 充值。
- 奖励发放。

验收：

- 桌面端和移动端可玩。
- 轨迹、碰撞和落点有稳定反馈。
- 单局时长控制在 15-45 秒。

### 阶段 2：游戏内奖励闭环

目标：让弹珠机成为可回访的轻量游戏。

范围：

- `playTickets` 概念草案。
- `gameCoins`、皮肤、徽章、称号。
- 每日免费次数。
- 每日任务送次数。
- 命中奖励只进入游戏内资产。

不接：

- AI 积分返还。
- 直接付费购买次数。
- 礼品卡或实物兑换。

验收：

- 用户不用充值也能每日试玩。
- 输赢不影响 AI 积分余额。
- 规则说明清晰，奖励无现金化表达。

### 阶段 3：平台福利活动

目标：把弹珠机接入账号资产层，作为充值赠送和任务福利。

范围：

- 充值 AI 积分时附赠 `playTickets`。
- 平台任务、签到、活动发放 `playTickets`。
- 命中高倍率后发放低额 `bonusCredits`。
- `bonusCredits` 只能用于 AI 能力，不能用于弹珠机。
- 每日 `bonusCredits` 获取上限。

验收：

- `paidCredits` 与 `bonusCredits` 分账清楚。
- 所有奖励发放都有审计记录。
- 概率、上限、有效期、用户限制写入活动规则。

### 阶段 4：直接购买次数评估

目标：仅在合规确认后评估是否允许购买弹珠机次数。

范围：

- 固定保底权益。
- 纯游戏内随机奖励。
- 低额 `bonusCredits` 活动奖励。

必须先完成：

- 法务确认。
- 概率公示方案。
- 未成年人限制。
- 防沉迷和日限额。
- 客诉和退款规则。

## 3. 后续任务建议

| 平台福利活动规则评审 | P2 | 写清充值赠送、每日上限和概率公示 |

## 4. 风险

- 概率奖励和平台积分绑定后，容易被用户理解为积分下注。
- 直接付费购买游戏次数比充值赠送次数风险更高。
- 奖励如果可用于 AI 能力，即使不能提现，也仍具有平台服务价值。
- 任何“投入积分，随机返更多积分”的口径都应避免。
