# 领取分片目录

**用途**：每次领取任务新增独立领取文件，减少多人同时修改 `docs/tasks/CLAIMS.md` 的冲突。

## 命名规则

`TXXX-<owner>.md`

示例：

- `T036-codex.md`
- `T015-dev-a.md`

## 推荐内容

```md
# TXXX：任务名称

- 领取人：
- 领取时间：
- 状态：
- 预计完成：
- 允许修改文件：
- 禁止修改文件：
- 依赖任务：
- 验证命令：
- 当前风险：
- 备注：
```

主领取文档 `docs/tasks/CLAIMS.md` 只保留当前进行中的任务、冲突登记和必要交接。完成任务后再把结果汇总回主文档。

运行 `npm run docs:sync` 可以把本目录中的领取分片汇总到主文档的自动生成摘要区。
