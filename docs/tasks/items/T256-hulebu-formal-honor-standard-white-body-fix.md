## 目标

消除 `东 / 南 / 西 / 北 / 中 / 发 / 白` 白色牌面中的双层边框和贴图感，使其完整使用万筒条同款标准白色牌体。

## 实现方式

- 以 `standard-body-blank.png` 作为每张字牌的完整底板。
- 从原字牌中提取字形或白板边框 alpha mask，只把内容层合成到标准底板。
- 为内容 mask 外的牌体一致性增加自动校验。

## 不做

- 不修改牌背。
- 不重新生成美术母版。
- 不接入 Cocos。

## 完成结果

- 7 张字牌全部改为标准空白牌体加独立内容层，不再保留旧字牌的整张白色牌体。
- 东南西北、中发通过颜色 mask 提取字形；白板只提取内侧黑色边框。
- 中、发、白额外使用内容 alpha 下限，剔除旧图中覆盖整个内容区的低透明度米白背景。
- 内容区之外与标准牌体逐像素一致，双层白色边框和贴图感已消除。
- formal v1 保持 35 张麻将牌、80 个唯一资源 key；validation report 状态为 `passed`。
- 牌背、其他 27 张数字牌和 Cocos 工程未修改。
