## 目标

清除 `中 / 发 / 白` 内容区域内由旧图纹理产生的离散背景残影，并重新设计结构合理的完整牌背。

## 实现方式

- 在 T256 的颜色与 alpha 阈值之后增加四连通域过滤。
- 只保留不接触内容边界且像素数达到阈值的大块内容。
- 使用 PPTOKEN 重新设计完整牌背母版，旧牌背只作青绿、金线和花纹风格参考。
- 新牌背必须是连续青绿面板加一层绿色底座，禁止白色/米白侧壁、双层绿色底座和局部拼接。

## 不做

- 不修改东南西北。
- 不接入 Cocos。

## 完成结果

- 中、发、白的严格内容 mask 增加四连通域过滤，只保留不接触提取边界且不少于 100 像素的真实内容块。
- 未上传任何本地参考图；通过 PPTOKEN 纯文字生成新的透明牌背母版 `master-sources/back-default-v2.png`。
- 新牌背是连续青绿玉石面板加一层约 9% 高度的深绿底座，无白色/米白侧壁、无双层绿色和局部拼接。
- 构建脚本裁切母版并映射到标准 alpha bbox `(27, 23, 246, 354)`；牌背底座区浅色像素计数为 0。
- formal v1 保持 35 张麻将牌、80 个唯一资源 key；validation report 状态为 `passed`。
- 东南西北、其他 27 张数字牌和 Cocos 工程未修改。
