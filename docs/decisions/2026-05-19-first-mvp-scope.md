# 决策：第一阶段 MVP 范围

**日期**：2026-05-19

## 背景

项目方向包含工具站、游戏站、AI 能力、订阅、自带 API 和后续 API 中转。范围很大，需要先限定第一阶段交付，避免一开始做散。

## 选项

1. 先做完整门户和大量工具/游戏。
2. 先做 AI 能力平台。
3. 先做两个工具和一个游戏，验证流量、停留和技术结构。

## 决策

选择第 3 个方案。

第一阶段只做：

- PDF 工具箱。
- AI 修图工具。
- 麻将 Roguelike 消除小游戏。

## 理由

- PDF 工具有明确搜索刚需。
- AI 修图能体现后续 AI 付费空间。
- 小游戏能验证停留时长。
- 三个模块足够覆盖工具、AI、游戏三条主线。

## 后续影响

- 不再第一阶段扩展大量工具。
- 不再第一阶段做完整 AI 能力平台。
- 所有计划和状态文档围绕这三个模块推进。
